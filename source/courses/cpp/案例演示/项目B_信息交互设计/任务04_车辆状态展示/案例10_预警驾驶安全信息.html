情境背景

高级驾驶辅助系统（ADAS）最基本的功能之一是对驾驶员和车辆状态的持续监控，如“未系安全带提醒”。这些“是/非”状态需要专门的数据类型精确表示——布尔型（bool）。本案例使用 bool 变量模拟并表示车辆关键安全状态。

案例要求

定义 bool isEngineOn（引擎状态）和 bool isSeatbeltFastened（安全带状态），模拟“引擎已启动（true）但安全带未系（false）”的场景，用 std::boolalpha 输出可读的状态报告。
源码核对重点：当前 main.cpp 只用 std::boolalpha 显示 isEngineOn 与 isSeatbeltFastened，没有条件预警分支；标题中的“预警”是应用情境。

ee_10/main.cpp
// 使用 bool 类型来表示和显示车辆状态

#include <iostream>
#include <iomanip> // std::boolalpha 将 bool 以 true/false 文本输出

int main() {
    bool isEngineOn = true;
    bool isSeatbeltFastened = false;

    std::cout << std::boolalpha;
    std::cout << "--- 驾驶安全状态监控 ---" << std::endl;
    std::cout << "引擎是否启动? " << isEngineOn << std::endl;
    std::cout << "安全带是否系好? " << isSeatbeltFastened << std::endl;
    std::cout << "安全规则：当引擎启动且安全带未系时，需要发出警报。" << std::endl;

    return 0;
}
