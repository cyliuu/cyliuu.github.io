情境背景

自动驾驶仿真需要实时追踪和更新环境中每个动态物体的位置。物体在二维平面上移动时，x、y 坐标通常根据不同的物理规则在同一时间步内更新。C++ 的逗号运算符允许在一个语句中执行多个操作，但当多种运算符混合时，计算顺序（优先级）就变得至关重要。

案例要求

定义两个 double 变量 x、y 初始化为 0.0，模拟三次连续更新。每次迭代 x 增加 2、y 变为更新后的 x 减去 5，且必须用逗号运算符把 x、y 的更新写在同一赋值语句中，每次迭代后打印 x、y 的当前值。
源码核对重点：逗号运算符在括号内按从左到右求值，整个表达式取最后子表达式的值；循环三轮后为 x=6、y=1。

// 使用逗号运算符说明运算符优先级

#include <iostream>
#include <iomanip>

int main() {
    double x = 0.0, y = 0.0;
    std::cout << std::fixed << std::setprecision(1);
    std::cout << "初始状态: x = " << x << ", y = " << y << std::endl;

    // 赋值运算符 '=' 的优先级低于逗号 ','，所以括号必须保留！
    // 逗号表达式从左到右：先 x += 2.0，再用新 x 算 x - 5.0，取最右结果赋给 y
    y = (x += 2.0, x - 5.0);   // x=2.0, y=-3.0
    std::cout << "第1次更新后: x = " << x << ", y = " << y << std::endl;

    y = (x += 2.0, x - 5.0);   // x=4.0, y=-1.0
    std::cout << "第2次更新后: x = " << x << ", y = " << y << std::endl;

    y = (x += 2.0, x - 5.0);   // x=6.0, y=1.0
    std::cout << "第3次更新后: x = " << x << ", y = " << y << std::endl;
    return 0;
}
