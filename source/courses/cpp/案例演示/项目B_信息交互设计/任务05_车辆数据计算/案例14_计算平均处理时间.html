情境背景

自动驾驶系统的车载主控芯片（ECU）需要在极短时间内处理海量传感器数据包，衡量其性能的关键指标是“平均处理耗时”。计算时若两个整数相除，小数部分会被无情丢弃，导致结果严重失真。本案例通过显式类型转换确保计算精度。

案例要求

定义 int total_seconds = 3（总耗时 3 秒）、int packets_processed = 1000（处理 1000 个数据包），计算每包平均耗时（毫秒）。先用整数除法观察错误结果，再用 static_cast<double>() 修正计算，得到精确结果。
源码核对重点：在除法发生之前把至少一个操作数转换为 double，才能保留小数；事后转换截断的整数无法恢复精度。

// 使用 static_cast 处理整数除法造成的精度损失

#include <iostream>
#include <iomanip>

int main() {
    int total_seconds = 3;
    int packets_processed = 1000;

    // 错误方式：整数除法 3 / 1000 = 0，小数被丢弃，0 * 1000 仍为 0
    double avg_time_ms_wrong = (total_seconds / packets_processed) * 1000;
    std::cout << "错误计算结果: " << avg_time_ms_wrong << " ms" << std::endl;

    // 正确方式：static_cast 先把 total_seconds 临时转成 double（3.0）
    double avg_time_ms_correct = (static_cast<double>(total_seconds) / packets_processed) * 1000;
    std::cout << "正确计算结果: "
              << std::fixed << std::setprecision(1)
              << avg_time_ms_correct << " ms" << std::endl;
    return 0;
}
