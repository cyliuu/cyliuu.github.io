案例背景

代码不仅是写给机器执行的，更是写给团队成员阅读和维护的。代码可读性的基石就是良好、规范的命名。随着人工智能的发展，AIGC 工具已具备强大的代码理解能力，能通过分析标识符的命名和代码结构来推断程序功能。本案例让你扮演“代码注释官”，借助 AIGC 为一段没有注释的代码添加注释，直观感受规范命名对于人机协作的重要性。

任务要求

将一段没有注释的 C++ 代码粘贴给任意 AIGC 工具（如 Kimi、ChatGPT、文心一言等），提出要求：“请为这段 C++ 代码添加详细注释，重点解释每个变量（标识符）的用途，以及关键代码块的逻辑”，观察 AI 如何通过 rectangle_length、area、perimeter 等标识符推断出程序功能。

案例代码、提示与输入
// 一段没有注释的C++代码片段

#include <iostream>

int main() {
    double rectangle_length = 10.5;
    double rectangle_width = 4.0;

    double area = rectangle_length * rectangle_width;
    double perimeter = 2 * (rectangle_length + rectangle_width);

    std::cout << "Rectangle Details:" << std::endl;
    std::cout << "Length: " << rectangle_length << std::endl;
    std::cout << "Width: " << rectangle_width << std::endl;
    std::cout << "Area: " << area << std::endl;
    std::cout << "Perimeter: " << perimeter << std::endl;

    return 0;
}
运行效果与分析

AIGC 能准确注释出 rectangle_length 是“矩形的长度”、area 是“面积”——因为它读懂了我们用英文单词起的标识符；而 int、double、return 这些关键字，AI 只说明作用、不解释含义，因为它们是语言内置的语法规则。

[提示] 可以把标识符改成无意义的单字母 l、w、a、p，再让 AIGC 注释一次，观察它还能否准确猜出每个变量的用途——这能直观体会规范命名的重要性。
