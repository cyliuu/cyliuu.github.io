情境背景

软件开发中经常需要用不同输入数据运行同一程序观察行为，手动重复编译运行繁琐低效。专业工程师编写自动化脚本来解决——脚本是包含多条命令的文本文件，计算机自动按顺序执行。

案例要求

编写行程计算器 travel_calculator.cpp（从命令行参数接收速度和时间，计算距离 = 速度 × 时间），再编写 Windows 批处理脚本 test.bat 和 Bash 脚本 test.sh，自动编译并连续三次传入不同参数调用程序。
源码核对重点：test.sh 编译 travel_calculator，检查编译命令退出状态；之后运行三组参数，但没有逐组检查程序退出状态。网页不在浏览器调用 Shell 或 C++。

eee_B1/travel_calculator.cpp
#include <iostream>
#include <cstdlib> // atof 函数

int main(int argc, char* argv[]) {
    if (argc < 3) {
        std::cout << "错误：参数不足！" << std::endl;
        std::cout << "用法: " << argv[0] << " [速度] [时间]" << std::endl;
        return 1;
    }
    double speed = std::atof(argv[1]);
    double time = std::atof(argv[2]);
    double distance = speed * time;
    std::cout << "速度: " << speed << " km/h, 时间: " << time << " h -> "
              << "距离: " << distance << " km" << std::endl;
    return 0;
}
eee_B1/test.sh
#!/bin/bash
# test.sh - Bash 自动化执行脚本
echo "--- 正在编译行程计算器... ---"
g++ travel_calculator.cpp -o travel_calculator

if [ $? -ne 0 ]; then
    echo "*** 编译失败！请检查代码和g++环境。 ***"
    exit 1
fi

echo "--- 开始自动化执行三个测试用例 ---"
./travel_calculator 100 2.5
./travel_calculator 80.5 0.5
./travel_calculator 0 10
echo "--- 自动化执行完成 ---"
