情境背景

在高级感知系统中，融合来自不同传感器（如激光雷达、摄像头）的数据是核心任务之一。然而，每个传感器都有自己独立的坐标系。例如，一个安装在车顶的激光雷达，它检测到的障碍物坐标是相对于它自身的，为了让车辆的决策模块能够统一处理，必须将这个坐标变换到车辆的基准坐标系下。这个变换过程涉及复杂的矩阵和向量运算，从零开始手写这些数学运算不仅繁琐且容易出错，因此工程师们广泛使用专业的线性代数库来完成任务。Eigen 就是其中最流行、最高效的 C++ 数学库之一。本案例将带你初次体验如何利用这个强大的第三方库，轻松解决一个典型的 3D 坐标变换问题。

案例要求

配置并使用 Eigen 库，将一个三维空间中的点绕 Z 轴旋转 90 度。配置环境：下载 Eigen 库并在 IDE 中正确配置头文件包含路径。表示点：在 main 函数中使用 Eigen::Vector3d 定义一个三维点 P，其坐标为 (1.0, 0.0, 0.0)。创建旋转矩阵：创建一个 Eigen::Matrix3d 对象，作为绕 Z 轴旋转 90 度的旋转矩阵。执行变换：通过矩阵与向量的乘法计算出旋转后的新点 P' 的坐标。打印结果：在控制台清晰地打印出旋转前和旋转后的点坐标，以验证计算的正确性。绕 Z 轴旋转 θ 度的旋转矩阵第一行为 [cosθ, -sinθ, 0]、第二行为 [sinθ, cosθ, 0]、第三行为 [0, 0, 1]。
源码核对重点：Eigen 构建旋转并作用于向量；浮点计算中应允许接近 0 的微小残差。

eee_D1/main.cpp
// 使用Eigen库进行3D坐标变换

#include <iostream>
#include <cmath> // 用于 M_PI (圆周率) 和三角函数

// 引入 Eigen 的主头文件
#include <Eigen/Dense>

int main() {
    // 定义一个三维点向量
    //    Vector3d 是 Eigen::Matrix<double, 3, 1> 的别名
    Eigen::Vector3d point(1.0, 0.0, 0.0);

    // 定义旋转角度 (90度) 并转换为弧度
    double angle_degrees = 90.0;
    double angle_radians = angle_degrees * M_PI / 180.0;

    // 创建绕Z轴的旋转矩阵
    //    Matrix3d 是 Eigen::Matrix<double, 3, 3> 的别名
    Eigen::Matrix3d rotation_matrix;
    // 使用逗号初始化器，按行优先顺序填充矩阵
    rotation_matrix << cos(angle_radians), -sin(angle_radians), 0,
                       sin(angle_radians),  cos(angle_radians), 0,
                       0,                   0,                  1;

    // 执行坐标变换：旋转后的点 = 旋转矩阵 * 原始点
    Eigen::Vector3d rotated_point = rotation_matrix * point;

    // 打印结果
    std::cout << "--- 3D坐标变换 (绕Z轴旋转90度) ---" << std::endl;
    std::cout << "原始点坐标 P:\n" << point << std::endl;
    std::cout << "\n旋转矩阵 Rz(90):\n" << rotation_matrix << std::endl;
    std::cout << "\n旋转后点坐标 P' = Rz * P:\n" << rotated_point << std::endl;

    return 0;
}
