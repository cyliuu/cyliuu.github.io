情境背景

除了分析已有的日志，我们常常需要扮演一个更主动的角色：创建这些日志。在车辆行驶过程中，感知系统每时每刻都在检测新的障碍物。为了进行后续的算法评估和问题追溯，将每一次的检测结果实时、永久地记录下来至关重要。这个将程序内存中的动态数据写入到硬盘文件以便长期保存的过程，就是数据持久化。本案例将教你如何使用 C++ 的文件输出流，模拟一个持续运行的障碍物检测系统，并将新的发现源源不断地追加到一个日志文件中，而不是覆盖旧的记录。

案例要求

编写一个程序，模拟障碍物检测与信息记录的过程。程序需要在一个循环中运行，模拟一个持续工作的检测系统；在循环的每一轮，提示用户输入新检测到的障碍物信息（例如类型和距离），用户可以输入一个特殊指令（如 "quit"）来结束检测。核心要求是，每当用户输入一条新的障碍物信息，程序都需要将其格式化为一个字符串，并以追加（append）模式写入到一个名为 detection_log.txt 的文件中；程序启动时应告知用户日志文件的名称，并在退出时提示日志已保存。
源码核对重点：std::ios::app 让写操作追加到文件末尾；网页演示文本变化，不会替用户修改真实日志文件。

// 使用 ofstream 以追加模式将障碍物信息写入文件

#include <iostream>
#include <fstream>  // 必须包含此头文件以使用文件流
#include <string>   // 包含此头文件以使用 std::string

int main() {
    // 定义一个 ofstream (output file stream) 对象
    // 第二个参数 std::ios::app 使文件以追加模式打开
    //    如果文件不存在，它会被创建;如果已存在，新内容将写入到文件末尾
    std::ofstream log_file("detection_log.txt", std::ios::app);

    // 检查文件是否成功打开以供写入
    if (!log_file.is_open()) {
        std::cerr << "错误: 无法打开或创建日志文件 detection_log.txt" << std::endl;
        return 1; // 异常退出
    }

    std::cout << "--- 障碍物检测与记录系统 ---" << std::endl;
    std::cout << "新的检测结果将被记录到 'detection_log.txt' 文件中。" << std::endl;
    std::cout << "请输入障碍物类型 (输入 'quit' 结束): ";

    // 准备用于接收用户输入的变量
    std::string type;
    double distance;

    // 启动一个循环，持续接收用户输入并写入文件
    while (std::cin >> type && type != "quit") {
        std::cout << "请输入该障碍物的距离 (米): ";
        std::cin >> distance;

        // 将格式化的数据写入文件
        //    操作方式与 std::cout 完全一样！
        log_file << "类型: " << type << ", 距离: " << distance << "m" << std::endl;

        std::cout << "  -> 记录已保存！" << std::endl;
        std::cout << "\n请输入下一个障碍物类型 (输入 'quit' 结束): ";
    }

    // 关闭文件，确保所有缓冲区中的数据都被写入磁盘
    log_file.close();

    std::cout << "\n系统已退出。所有检测记录已保存到 detection_log.txt。" << std::endl;

    return 0;
}
