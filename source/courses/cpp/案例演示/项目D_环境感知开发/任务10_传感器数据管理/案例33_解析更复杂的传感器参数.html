情境背景

随着车载设备功能的日益强大，简单的固定指令已无法满足复杂的配置需求。现代设备通常支持更灵活的参数化设置，允许工程师通过发送包含多个部分的指令字符串，来精细地调整其工作模式。对于这种包含多个、由空格隔开部分的复杂字符串，使用传统的 C 风格函数进行解析，不仅代码繁琐，而且容易产生安全漏洞。为了解决这个问题，C++ 标准库提供了一个功能强大且安全的现代化工具——std::string 类。

案例要求

编写一个程序，用于解析一条更复杂的、由空格分隔的传感器参数设置指令。在 main 函数中，定义一个 std::string 类型的变量 command，并将其初始化为指令 "SET_PARAM lidar_range 100"。核心要求是，利用 std::string 类提供的成员函数（如 .find() 和 .substr()），从原始指令字符串中准确地分离出三个组成部分——指令名 "SET_PARAM"、参数名 "lidar_range"、参数值 "100"——并将解析出的三个部分分别存储在新的 std::string 变量中，清晰地打印到控制台。
源码核对重点：std::string::find 找分隔符，substr 依据位置切出三段；实际解析还应考虑缺少空格等异常输入。

// 使用 std::string 类解析复杂的传感器参数指令

#include <iostream>
#include <string> // 必须包含此头文件以使用 std::string

int main() {
    // 定义一个 std::string 对象来存储完整的指令
    std::string command = "SET_PARAM lidar_range 100";
    std::cout << "原始指令: \"" << command << "\"" << std::endl;
    std::cout << "----------------------------------------" << std::endl;

    // 开始解析

    // 查找第一个空格的位置
    //    .find() 会返回找到的第一个字符的索引，如果找不到则返回一个特殊值
    size_t pos1 = command.find(' ');

    // 提取第一个部分（指令名）
    //    .substr(起始索引, 长度) 用于截取子字符串
    std::string command_name = command.substr(0, pos1);

    // 查找第二个空格的位置
    //    .find() 的第二个参数是查找的起始位置，我们从第一个空格之后开始找
    size_t pos2 = command.find(' ', pos1 + 1);

    // 提取第二个部分（参数名）
    //    子字符串的起始位置是第一个空格之后 (pos1 + 1)
    //    长度是第二个空格的位置减去第一个空格后的位置
    std::string param_name = command.substr(pos1 + 1, pos2 - (pos1 + 1));

    // 提取第三个部分（参数值）
    //    .substr() 如果只给一个参数（起始索引），它会一直截取到字符串末尾
    std::string param_value = command.substr(pos2 + 1);

    // 打印解析结果
    std::cout << "解析结果:" << std::endl;
    std::cout << "  - 指令名: " << command_name << std::endl;
    std::cout << "  - 参数名: " << param_name << std::endl;
    std::cout << "  - 参数值: " << param_value << std::endl;

    return 0;
}
