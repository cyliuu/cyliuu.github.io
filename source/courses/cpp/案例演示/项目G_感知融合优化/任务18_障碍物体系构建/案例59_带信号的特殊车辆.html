情境背景

在现实世界的交通系统中，存在许多功能复合的特殊车辆。例如，一辆救护车，它既具备普通车辆的行驶能力（是一种车辆），又拥有独立的警报和信号功能（是一种信号装置）。这种对象同时扮演多个角色的情况，在软件设计中非常普遍。为了精确地描述这种“is-a... and is-also-a...”的复杂关系，面向对象编程提供了多继承机制。通过多继承，一个派生类可以同时从多个基类中继承属性和方法，将不同领域的专长融合于一身。

案例要求

设计 Ambulance 类，使其经由多继承同时具备 Vehicle 与 SignalingDevice 的功能：前者包含 speed、set_speed() 和 display_status()，后者包含 signal_on、turn_on()、turn_off() 和同名 display_status()；救护车以 public 同时继承二者、在构造函数中初始化两个基类，并以 display_all_info() 消除同名方法的二义性。在 main 中调用继承方法和完整状态展示方法验证结果。
源码核对重点：同名成员造成候选歧义，需要明确指定基类作用域，或在派生类中定义自己的整合接口。

#include <iostream>

// 基类 1：车辆
class Vehicle {
public:
    Vehicle(double s) : speed(s) {}

    void set_speed(double s) {
        speed = s;
        std::cout << "[Vehicle] 速度设置为: " << speed << " km/h" << std::endl;
    }

    // 车辆的状态显示
    void display_status() const {
        std::cout << "  - 车辆状态: 当前速度 " << speed << " km/h" << std::endl;
    }

protected:
    double speed;
};

// 基类 2：信号装置
class SignalingDevice {
public:
    SignalingDevice(bool on) : signal_on(on) {}

    void turn_on() {
        signal_on = true;
        std::cout << "[Signal] 信号已开启。" << std::endl;
    }

    void turn_off() {
        signal_on = false;
        std::cout << "[Signal] 信号已关闭。" << std::endl;
    }

    // 信号装置的状态显示
    void display_status() const {
        std::cout << "  - 信号状态: " << (signal_on ? "开启" : "关闭") << std::endl;
    }

protected:
    bool signal_on;
};

// 派生类：救护车，同时继承 Vehicle 和 SignalingDevice
class Ambulance : public Vehicle, public SignalingDevice {
public:
    // 构造函数需要分别调用两个基类的构造函数进行初始化
    Ambulance(double initial_speed, bool signal_status)
        : Vehicle(initial_speed), SignalingDevice(signal_status) {}

    // 定义一个新方法来解决 display_status 的命名冲突
    void display_all_info() const {
        std::cout << "--- 救护车(ID: " << this << ") 综合状态 ---" << std::endl;
        // 使用作用域解析运算符 :: 来明确指定调用哪个基类的成员函数
        Vehicle::display_status();
        SignalingDevice::display_status();
    }
};

int main() {
    // 创建一个多继承的派生类对象
    Ambulance ambulance1(80.0, true);

    // 验证它可以调用来自不同基类的功能
    ambulance1.set_speed(90.5);
    ambulance1.turn_off();

    // 调用自己定义的、解决了二义性的方法
    ambulance1.display_all_info();

    // 尝试直接调用同名函数，会导致二义性编译错误
    // ambulance1.display_status();
    // 错误: request for member 'display_status' is ambiguous

    return 0;
}
