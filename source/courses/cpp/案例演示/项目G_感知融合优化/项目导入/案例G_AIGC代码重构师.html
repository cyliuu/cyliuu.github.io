案例背景

在开发复杂的软件系统时，我们常常需要处理多种功能相似但实现各异的组件，例如不同类型的传感器（激光雷达、毫米波雷达）或数据解析器。如果为每一种组件都编写一个完全独立的类，就会导致大量逻辑重复的代码。这种设计不仅增加了代码量，也使得未来的维护和扩展（例如增加一种新的传感器）变得异常困难和容易出错。为了追求更卓越、更具扩展性的软件设计，我们必须引入面向对象的核心特性——封装、继承和多态。在本案例中，你将扮演一名“代码重构师”，借助 AIGC 的智慧，分析两段功能相似但独立的传感器代码，并提出一个使用继承进行重构的优化方案。

任务要求

使用 AIGC 工具分析两个功能相似但独立实现的传感器类 LidarSensor 和 RadarSensor，明确指出 get_status()、reset() 等重复代码；要求其以资深软件架构师视角提出基于继承的重构方案，并分析如何用 Sensor 基类提取共性、以虚函数实现多态和可扩展性。

[提示] 本案例包含后续将学习的继承、虚函数、多态和智能指针等内容。此时不要求掌握全部语法，重点比较重构前后的公共接口、重复代码和调用方式。

class LidarSensor {

运行效果与分析

AIGC 生成的 C++ 重构方案代码（示例）如下：

#include <iostream>
#include <string>
#include <vector>
#include <memory>

// 创建一个抽象的Sensor基类
class Sensor {
public:
    // 提供一个虚析构函数，这是作为基类的良好实践
    virtual ~Sensor() {}

    // 纯虚函数，强制所有派生类必须实现自己的初始化逻辑
    virtual void initialize() = 0;

    // 虚函数，提供一个默认的、可被重写的重置逻辑
    virtual void reset() {
        std::cout << "  -> 执行通用的重置逻辑..." << std::endl;
    }

    // 纯虚函数，强制所有派生类必须报告自己的状态
    virtual std::string get_status() const = 0;

    // 纯虚函数，定义统一的数据处理接口
    virtual void process_data() = 0;
};

// LidarSensor 继承自 Sensor
class LidarSensor : public Sensor {
public:
    void initialize() override {
        std::cout << "初始化Lidar传感器..." << std::endl;
    }

    std::string get_status() const override {
        return "Lidar OK";
    }

    void process_data() override {
        std::cout << "  -> 正在处理激光点云数据..." << std::endl;
    }
};

// RadarSensor 继承自 Sensor
class RadarSensor : public Sensor {
public:
    void initialize() override {
        std::cout << "初始化Radar传感器..." << std::endl;
    }

    std::string get_status() const override {
        return "Radar OK";
    }

    void process_data() override {
        std::cout << "  -> 正在处理毫米波雷达回波..." << std::endl;
    }

    // 注意：RadarSensor没有重写reset()，它将自动使用基类提供的通用版本
};

// 用于测试的 main 函数
int main() {
    // 使用智能指针和基类指针来管理不同的传感器对象
    std::vector<std::unique_ptr<Sensor>> sensors;
    sensors.push_back(std::make_unique<LidarSensor>());
    sensors.push_back(std::make_unique<RadarSensor>());

    // 多态的应用：通过统一的接口，处理不同类型的传感器
    for (const auto& sensor : sensors) {
        sensor->initialize();
        sensor->process_data();
        sensor->reset();
        std::cout << "传感器状态: " << sensor->get_status() << std::endl;
        std::cout << "--------------------" << std::endl;
    }

    return 0;
}

初始化Radar传感器...

  -> 执行通用的重置逻辑...

现象分析：通过创建一个 Sensor 基类，将所有传感器共有的行为（如 initialize、reset、get_status、process_data）的接口都集中到了基类中；对于像 reset 这样逻辑完全一样的功能，直接在基类中实现，供所有子类复用（继承）。而在 main 函数中使用 std::vector<std::unique_ptr<Sensor>> 统一管理不同类型的传感器，运行时根据指针实际指向的对象调用对应的 process_data 版本（多态）。这正是虚函数和动态绑定的威力。

[提示] 案例中出现的 std::unique_ptr、std::make_unique 是 C++ 的智能指针，属于“黑盒”工具，用于自动管理动态内存，其原理将在后续深入，这里先拿来用。

// 重构前版本：两个独立类具有重复接口

#include <iostream>
#include <string>

class LidarSensor {
public:
    void initialize() { std::cout << "初始化Lidar传感器..." << std::endl; }
    void reset() { std::cout << "重置Lidar传感器..." << std::endl; }
    std::string get_status() const { return "Lidar OK"; }
    void process_point_cloud() { std::cout << "处理激光点云数据..." << std::endl; }
};

class RadarSensor {
public:
    void initialize() { std::cout << "初始化Radar传感器..." << std::endl; }
    void reset() { std::cout << "重置Radar传感器..." << std::endl; }
    std::string get_status() const { return "Radar OK"; }
    void process_radar_echo() { std::cout << "处理毫米波雷达回波..." << std::endl; }
};

int main() {
    LidarSensor lidar;
    RadarSensor radar;
    lidar.initialize();
    lidar.process_point_cloud();
    radar.initialize();

variant_2/main.cpp
// 重构后版本：以统一的 Sensor 接口消除重复

#include <iostream>
#include <memory>
#include <string>
#include <vector>

class Sensor {
public:
    virtual ~Sensor() = default;
    virtual void initialize() = 0;
    virtual void reset() {
        std::cout << "  -> 执行通用的重置逻辑..." << std::endl;
    }
    virtual std::string get_status() const = 0;
    virtual void process_data() = 0;
};

class LidarSensor final : public Sensor {
public:
    void initialize() override { std::cout << "初始化Lidar传感器..." << std::endl; }
    std::string get_status() const override { return "Lidar OK"; }
    void process_data() override { std::cout << "  -> 正在处理激光点云数据..." << std::endl; }
};

class RadarSensor final : public Sensor {
public:
    void initialize() override { std::cout << "初始化Radar传感器..." << std::endl; }
    std::string get_status() const override { return "Radar OK"; }
    void process_data() override { std::cout << "  -> 正在处理毫米波雷达回波..." << std::endl; }
};

int main() {
    std::vector<std::unique_ptr<Sensor>> sensors;
    sensors.push_back(std::make_unique<LidarSensor>());
    sensors.push_back(std::make_unique<RadarSensor>());

    for (const auto& sensor : sensors) {
        sensor->initialize();
        sensor->process_data();
        sensor->reset();
        std::cout << "传感器状态: " << sensor->get_status() << "\n--------------------" << std::endl;
    }
    return 0;
}
