情境背景

在学习了 if-else if-else 结构后，我们已经能够处理基于不同条件区间的“多选一”问题。但这就像一个保安，需要挨个盘问：“你的速度大于 100 吗？不是。那你的速度大于 60 吗？...”。现在，我们面临一个更直接的场景：车载多媒体系统。用户通过中控屏幕上的数字按钮（1-音乐，2-导航，3-电话）来选择功能。这是一个根据单个变量的多个特定、离散的值进行选择的场景。在这种情况下，使用一长串 if-else if 会显得冗长且效率不高。为了更优雅、更高效地解决这类问题，C++ 提供了一个专门的“分发中心”——switch 开关语句。

案例要求

编写一个 C++ 程序模拟简单的车载多媒体控制台：显示功能菜单，使用 std::cin 读取用户输入的 1–4 选项，并以 switch-case 分派到对应功能（用打印信息模拟）；对于无效输入给出提示。
源码核对重点：switch 的 default 用于不匹配现有 case 的输入；break 防止已命中分支继续贯穿。

ee_21/main.cpp
// 使用 switch-case 语句实现多媒体功能选择

#include <iostream>

int main() {
    // 显示功能菜单
    std::cout << "--- 车载多媒体系统 ---" << std::endl;
    std::cout << "1. 播放音乐" << std::endl;
    std::cout << "2. 使用导航" << std::endl;
    std::cout << "3. 拨打电话" << std::endl;
    std::cout << "4. 切换到收音机" << std::endl;
    std::cout << "--------------------------" << std::endl;

    // 定义变量并获取用户输入
    int choice;
    std::cout << "请输入您的选择 (1-4): ";
    std::cin >> choice;

    // 使用 switch 语句进行功能分派
    // switch 会检查 'choice' 变量的值
    switch (choice) {
        // 如果 choice 的值等于 1，程序会跳转到这里执行
        case 1:
            std::cout << "正在播放音乐..." << std::endl;
            break; // 执行完当前分支后跳出 switch 结构

        // 如果 choice 的值等于 2
        case 2:
            std::cout << "正在使用导航..." << std::endl;
            break;

        // 如果 choice 的值等于 3
        case 3:
            std::cout << "正在拨打电话..." << std::endl;
            break;

        // 如果 choice 的值等于 4
        case 4:
            std::cout << "已切换到收音机。" << std::endl;
            break;

        // 如果 choice 的值不匹配以上任何一个 case
        default:
            std::cout << "错误：无效的选项。" << std::endl;
            break; // default 后的 break 虽然不是必需的，但保持一致性是好习惯
    }

    return 0;
}
