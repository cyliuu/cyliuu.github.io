情境背景

在对一个对象进行一系列连续的设置或操作时，我们通常会写出多行独立的代码。例如，要配置一辆新车，我们可能会这样做：my_car.set_speed(100); my_car.set_lane(2); my_car.set_color("Red");。这种写法虽然功能正确，但在代码风格上显得有些冗余和松散。现代软件开发，尤其是在设计库和框架时，推崇一种名为“流式接口”（Fluent Interface）的编程风格，它允许我们将多个操作链接成一条语句，使代码读起来更像自然语言，例如：my_car.set_speed(100).set_lane(2).set_color("Red");。为了实现这种优雅的“链式调用”，每个成员函数在完成自己的任务后必须返回对象自身的引用。在 C++ 的成员函数内部，this 指针是一个特殊的、由编译器隐式提供的指针，它永远指向调用该函数的当前对象实例，通过返回 *this，我们便能轻松实现这种强大的编程技巧。

案例要求

改造 Vehicle 的成员函数，利用 this 实现链式调用：类含 speed、lane 等私有成员及 set_speed()、set_lane() 等公共设置函数；将这些函数的返回类型由 void 改为 Vehicle&，并以 return *this; 返回当前对象。在 main 中使用单行链式调用完成配置，再以 display() 验证最终状态。
源码核对重点：返回当前对象的引用，使后续 .set_lane(2) 继续作用于同一对象；链式调用结束状态如 speed=80、lane=2。

ee_53/main.cpp
// 使用 this 指针实现链式调用

#include <iostream>

class Vehicle {
public:
    // 构造函数
    Vehicle(int id) : vehicle_id(id), speed(0.0), lane(1) {}

    // set_speed 函数
    //    - 返回类型为 Vehicle&，即对 Vehicle 对象的引用
    Vehicle& set_speed(double new_speed) {
        this->speed = new_speed;
        // 'this' 是一个指向当前对象的指针
        //    '*this' 就是当前对象本身
        //    返回 *this 使得可以继续对该对象进行其他操作
        return *this;
    }

    // set_lane 函数，同样返回 Vehicle&
    Vehicle& set_lane(int new_lane) {
        this->lane = new_lane;
        return *this; // 返回当前对象的引用
    }

    // display 函数用于显示对象状态，它不需要参与链式调用，返回 void 即可
    void display() const {
        std::cout << "--- 车辆状态报告 ---" << std::endl;
        std::cout << "车辆 ID: " << vehicle_id << std::endl;
        std::cout << "当前速度: " << speed << " km/h" << std::endl;
        std::cout << "所在车道: " << lane << std::endl;
    }

private:
    int vehicle_id;
    double speed;
    int lane;
};

// 程序入口展示链式调用
int main() {
    // 创建一个 Vehicle 对象
    Vehicle my_car(101);

    std::cout << "使用链式调用配置车辆..." << std::endl;

    // 链式调用 (Chained Method Calls)
    //    my_car.set_speed(80.0) 执行后返回 my_car 自身的引用,
    //    然后该引用继续调用 .set_lane(2)
    my_car.set_speed(80.0).set_lane(2);

    // 验证配置结果
    my_car.display();

    return 0;
}
