案例任务与源码核对

情境背景

在高性能的实时系统中，例如自动驾驶仿真、游戏引擎或高频交易系统，程序需要以极高的频率创建和销毁大量的小对象。以我们的仿真系统为例，GPS 接收器可能每秒都会产生数百个数据点（GPSDataPoint）。如果每次都使用标准的 new 和 delete 操作符在堆（Heap）上动态分配和释放内存，将会带来两个严重的性能问题：一是时间开销（new 和 delete 是相对较慢的操作，因为它们通常需要调用操作系统内核来进行内存管理，这涉及到加锁、查找合适的内存块等复杂步骤）；二是内存碎片（频繁地申请和释放大小不一的内存块，容易在堆上产生大量不连续的小空闲块，导致即使总的空闲内存足够，也可能无法分配出一个较大的连续内存块）。为了解决这个问题，一种高效的内存管理技术——内存池 (Memory Pool) 应运而生，其核心思想是在程序启动时一次性向操作系统申请一大块连续的内存，然后由程序自己来管理这块内存的分配和回收，避免频繁的系统调用并从根本上消除内存碎片问题。
背景说明与实现边界：“每次 new/delete 通常调用操作系统”“内存池从根本上消除碎片”不宜当作普遍结论，实际行为取决于分配器和工作负载。当前 GPSDataPool 没有处理容量为 0 的输入；性能倍数的计算也没有防范毫秒计时结果为 0。本页只讲空闲链表的设计意图，不把该实现作为可直接复用的生产级模板。

案例要求

设计并实现面向 GPSDataPoint 的简单内存池，与标准 new/delete 比较性能。GPSDataPoint 包含经度、纬度和时间戳；GPSDataPool 在构造时一次性预分配大量对象，用空闲链表管理未使用内存块，并提供 allocate() 与 deallocate()。在 main 中分别大量执行标准分配/释放和内存池分配/回收，通过输出比较两种方法的执行效率。
源码核对重点：池化可能降低频繁 new/delete 的成本，但性能依赖工作负载；需要核查池容量、对齐、构造析构与线程安全。

// 设计并实现一个简单的对象内存池

#include <iostream>
#include <vector>
#include <chrono> // 用于计时

// 需要频繁创建和销毁的对象
struct GPSDataPoint {
    double longitude;
    double latitude;
    long long timestamp;
};

// 为 GPSDataPoint 设计的内存池
class GPSDataPool {
public:
    // 构造函数，指定池的大小
    explicit GPSDataPool(size_t size) : pool_size_(size) {
        // 一次性申请大块内存
        pool_ = new GPSDataPoint[pool_size_];

        // 将所有内存块串成一个空闲链表
        // 这里用一种技巧：将下一个空闲块的地址存放在当前空闲块本身的空间里
        for (size_t i = 0; i < pool_size_ - 1; ++i) {
            // reinterpret_cast 用于在指针类型间进行底层转换
            *reinterpret_cast<GPSDataPoint**>(&pool_[i]) = &pool_[i + 1];
        }
        // 链表末尾指向 nullptr
        *reinterpret_cast<GPSDataPoint**>(&pool_[pool_size_ - 1]) = nullptr;

        // free_list_ 指向第一个空闲块
        free_list_ = &pool_[0];
    }

    // 析构函数，释放整个池的内存
    ~GPSDataPool() {
        delete[] pool_;
    }

    // 分配一个对象
    GPSDataPoint* allocate() {
        if (free_list_ == nullptr) {
            // 如果内存池耗尽，可以返回空指针或抛出异常
            return nullptr; 
        }
        // 从空闲链表头部取下一个节点
        GPSDataPoint* head = free_list_;
        free_list_ = *reinterpret_cast<GPSDataPoint**>(head);
        return head;
    }

    // 回收一个对象
    void deallocate(GPSDataPoint* ptr) {
        if (ptr == nullptr) return;
        // 将回收的节点作为新的头节点，插入到空闲链表头部
        *reinterpret_cast<GPSDataPoint**>(ptr) = free_list_;
        free_list_ = ptr;
    }

private:
    GPSDataPoint* pool_;      // 指向内存池的起始地址
    GPSDataPoint* free_list_; // 指向空闲链表的头部
    size_t pool_size_;

    // 禁止拷贝和赋值
    GPSDataPool(const GPSDataPool&) = delete;
    GPSDataPool& operator=(const GPSDataPool&) = delete;
};

int main() {
    const int ALLOCATIONS = 100000;
    const int LOOPS = 100;

    std::cout << "--- 性能对比测试 ---" << std::endl;
    std::cout << "每次循环分配和释放 " << ALLOCATIONS << " 个对象, 共循环 " << LOOPS << " 次。\n" << std::endl;

    // 测试用例 A：使用 new / delete
    auto start_time = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < LOOPS; ++i) {
        std::vector<GPSDataPoint*> ptrs;
        ptrs.reserve(ALLOCATIONS);
        for (int j = 0; j < ALLOCATIONS; ++j) {
            ptrs.push_back(new GPSDataPoint());
        }
        for (GPSDataPoint* ptr : ptrs) {
            delete ptr;
        }
    }
    auto end_time = std::chrono::high_resolution_clock::now();
    auto duration_new_delete = std::chrono::duration_cast<std::chrono::milliseconds>(end_time - start_time).count();
    std::cout << "方法 A (new/delete) 总耗时: " << duration_new_delete << " 毫秒" << std::endl;

    // 测试用例 B：使用内存池
    GPSDataPool pool(ALLOCATIONS); // 创建一个足够大的内存池
    start_time = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < LOOPS; ++i) {
        std::vector<GPSDataPoint*> ptrs;
        ptrs.reserve(ALLOCATIONS);
        for (int j = 0; j < ALLOCATIONS; ++j) {
            ptrs.push_back(pool.allocate());
        }
        for (GPSDataPoint* ptr : ptrs) {
            pool.deallocate(ptr);
        }
    }
    end_time = std::chrono::high_resolution_clock::now();
    auto duration_pool = std::chrono::duration_cast<std::chrono::milliseconds>(end_time - start_time).count();
    std::cout << "方法 B (Memory Pool) 总耗时: " << duration_pool << " 毫秒" << std::endl;

    std::cout << "\n性能提升倍数: " << static_cast<double>(duration_new_delete) / duration_pool << " 倍" << std::endl;

    return 0;
}
