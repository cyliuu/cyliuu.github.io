情境背景

在自动驾驶的感知和控制系统中，涉及大量的几何与三角函数运算。例如，激光雷达（Lidar）扫描返回的角度数据、GPS 和惯性测量单元（IMU）提供的航向角，通常是以“度”（degree）为单位，因为这更符合人类的直觉。然而，C++ 标准库（<cmath>）中的所有三角函数，如 sin、cos、tan，都要求输入参数为“弧度”（radian）。因此，在算法的实现过程中，角度与弧度之间的转换是一个极其频繁的操作。在一个典型的仿真循环或传感器数据处理流程中，这个转换函数可能每秒被调用成千上万次。虽然转换逻辑本身非常简单，但频繁的函数调用会带来不可忽视的性能开销（如堆栈操作、指令跳转等）。为了消除这种开销，追求极致的运行效率，内联函数成为了解决此类问题的最佳实践。

案例要求

编写一个高效的、用于将角度转换为弧度的内联函数。创建一个名为 to_radians 的函数，其返回类型为 double；该函数接收一个 double 类型的参数 degrees（表示角度值）；在函数声明前使用 inline 关键字，向编译器建议将此函数内联；函数内部根据公式 弧度 = 角度 * PI / 180.0 进行计算并返回结果，PI 值应定义为一个高精度的 const double 常量；在 main 函数中，多次调用此 inline 函数，转换几个常用角度（如 30°、90°、180°）并打印结果，以验证其正确性；在代码注释中，简要讨论为什么 inline 关键字适合用于这种短小且会被频繁调用的函数。
源码核对重点：inline 不保证机器码一定展开，也不能据此宣称固定性能增益；此例重点是角度到弧度的正确换算。

// 使用内联函数高效地进行角度到弧度的转换

#include <iostream>
#include <iomanip> // 用于格式化输出

// 定义一个高精度的PI常量
const double PI = 3.14159265358979323846;

// 定义内联函数
// inline 关键字建议编译器将函数体在调用处直接展开，以消除函数调用开销
// 这对于像 to_radians 这样简短且需要被频繁调用的函数，能有效提升性能
inline double to_radians(double degrees) {
    return degrees * PI / 180.0;
}

int main() {
    std::cout << "--- 角度-弧度转换器 ---" << std::endl;
    std::cout << std::fixed << std::setprecision(6); // 设置输出格式

    // 多次调用内联函数
    double angle1 = 30.0;
    double angle2 = 90.0;
    double angle3 = 180.0;

    double radians1 = to_radians(angle1);
    double radians2 = to_radians(angle2);
    double radians3 = to_radians(angle3);

    // 打印结果
    std::cout << angle1 << " 度 = " << radians1 << " 弧度" << std::endl;
    std::cout << angle2 << " 度 = " << radians2 << " 弧度" << std::endl;
    std::cout << angle3 << " 度 = " << radians3 << " 弧度" << std::endl;

    // 模拟在循环中频繁调用
    double sum_of_radians = 0.0;
    for(int i = 0; i < 1000000; ++i) {
        sum_of_radians += to_radians(1.0); // 在性能敏感的循环中调用
    }
    std::cout << "\n模拟百万次调用完成。" << std::endl;

    return 0;
}
