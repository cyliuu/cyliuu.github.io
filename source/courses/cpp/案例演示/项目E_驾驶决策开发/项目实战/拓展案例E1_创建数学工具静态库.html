案例任务与源码核对

情境背景

在一个大型软件项目中，我们常常会开发出许多独立的、功能专一的通用函数，例如用于安全计算或数据处理的数学函数。起初，这些函数可能散落在不同的文件中，或者与主程序的逻辑混杂在一起。在专业的软件工程实践中，为了实现代码的最大化复用和模块化，这些通用的功能单元通常会被编译成库文件。这就像将常用的工具（如扳手、螺丝刀）整理到一个工具箱里，任何需要这些工具的项目都可以直接使用这个“工具箱”，而无需关心工具内部是如何制造的。本案例将引导我们亲手打造第一个这样的“数学工具箱”——一个静态库。

案例要求

将之前编写的多个数学函数整合到一个独立的模块中，并将其编译成一个静态库（在 Linux/macOS 下为 .a 文件，在 Windows 下为 .lib 文件），然后编写一个全新的主程序，通过链接这个静态库来使用其中的函数。创建一个清晰的目录结构，将库的源码和主程序的源码分离开；库的实现：创建一个头文件 math_utils.h，用于声明所有对外提供的数学函数，创建一个源文件 math_utils.cpp，用于实现这些函数；库的编译：学习并使用底层的命令行工具（g++ 和 ar）来手动完成静态库的编译打包过程，深刻理解其原理；库的使用：编写 main.cpp，它 #include "math_utils.h" 并调用库中的函数；最终链接：学习如何在编译主程序时，链接我们自己创建的静态库。
源码核对重点：头文件供编译识别接口，静态库归档提供实现，最终链接必须包含库；网页仅解释构建链。

eee_E1/main.cpp
// 一个独立的主程序，用于链接并使用我们创建的数学库

#include <iostream>
#include "math_lib/math_utils.h" // 包含库的头文件

int main() {
    double speed = 100.0; // 100 km/h
    double angle = 45.0;  // 45 度

    // 调用来自静态库的函数
    double distance = calculate_braking_distance(speed);
    double radians = to_radians(angle);

    std::cout << "--- 数学库测试 ---" << std::endl;
    std::cout << "车速 " << speed << " km/h 的刹车距离是： " << distance << " 米" << std::endl;
    std::cout << angle << " 度对应的弧度是： " << radians << std::endl;

    return 0;
}

// math_lib/math_utils.h

// 数学工具库的公共头文件，提供函数声明

#ifndef MATH_UTILS_H
#define MATH_UTILS_H

// 声明：计算刹车距离
double calculate_braking_distance(double speed_kmh);

// 声明：角度转弧度
double to_radians(double degrees);

#endif // MATH_UTILS_H
eee_E1/math_lib/math_utils.cpp
// math_lib/math_utils.cpp

// 数学工具库的函数实现

#include "math_utils.h"
#include <cmath>

const double PI = 3.1415926535;

double calculate_braking_distance(double speed_kmh) {
    const double DECELERATION = 4.5;
    double speed_mps = speed_kmh / 3.6;
    return std::pow(speed_mps, 2) / (2 * DECELERATION);
}

double to_radians(double degrees) {
    return degrees * PI / 180.0;
}
