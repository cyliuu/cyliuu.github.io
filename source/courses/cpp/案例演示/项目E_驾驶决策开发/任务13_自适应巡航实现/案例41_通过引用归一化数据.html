情境背景

在自动驾驶的感知系统中，机器学习模型扮演着至关重要的角色。这些模型（如神经网络）需要处理来自不同传感器的海量数据，例如激光雷达返回的距离（可能从 0 到 200 米）、摄像头图像的像素亮度（0 到 255）等。一个常见的问题是，不同数据的数值范围（尺度）差异巨大，如果直接将这些原始数据“喂”给模型，尺度较大的数据可能会不成比例地“压制”尺度较小的数据，影响模型的学习效果。因此，数据归一化是一个至关重要的预处理步骤，它通过数学变换，将所有不同来源的数据都缩放到一个固定的、统一的区间（通常是 [0, 1]），确保所有特征都在同一起跑线上。为了追求最高效率，我们希望这个函数能够“就地”修改原始数据，而不是创建一个修改后的副本再返回，这就需要我们运用引用传参的强大功能。

案例要求

编写一个函数 normalize，它使用引用传参的方式，对一个浮点数进行“最小-最大规范化”，将其值“就地”缩放到 [0, 1] 区间。创建一个名为 normalize 的函数，其返回类型为 void；该函数接收三个参数：float& value（需要被归一化的数值，关键在于，它必须是一个引用）、float min_value（原始数据范围的最小值）、float max_value（原始数据范围的最大值）；函数体内，根据公式 归一化值 = (原始值 - 最小值) / (最大值 - 最小值) 计算新值，并直接赋给 value；在 main 函数中，定义一个变量模拟传感器读数（例如，一个在 [10, 90] 米范围内变化的雷达距离），打印其原始值，然后调用 normalize 函数，最后再次打印该变量的值，以验证它是否已被成功修改。
源码核对重点：非常量引用绑定实参本体；按 (50−10)/(90−10)=0.5 更新原变量。

// 使用引用传参，就地修改变量以实现数据归一化

#include <iostream>
#include <iomanip>

// 函数定义
// 功能： 对一个浮点数进行最小-最大规范化，缩放到[0, 1]区间
// 参数：
//   - value: 需要被归一化的数 (通过引用传递，会被直接修改)
//   - min_value: 原始数据范围的最小值
//   - max_value: 原始数据范围的最大值
void normalize(float& value, float min_value, float max_value) {
    // 检查分母是否为零，避免除零错误
    if (max_value - min_value == 0) {
        value = 0; // 或者根据业务逻辑处理
        return;
    }

    // 直接修改传入的 value 变量
    value = (value - min_value) / (max_value - min_value);
}

int main() {
    // 模拟一个雷达传感器读数，其有效范围是 10.0米 到 90.0米
    const float LIDAR_MIN_RANGE = 10.0f;
    const float LIDAR_MAX_RANGE = 90.0f;
    float sensor_reading = 50.0f; // 当前的测量值

    std::cout << "--- 传感器数据归一化 ---" << std::endl;
    std::cout << std::fixed << std::setprecision(4); // 设置输出格式

    std::cout << "调用 normalize 函数前， 原始读数： " << sensor_reading << std::endl;

    // 调用函数。因为是引用传参，函数将直接操作 sensor_reading 变量
    normalize(sensor_reading, LIDAR_MIN_RANGE, LIDAR_MAX_RANGE);

    std::cout << "调用 normalize 函数后， 归一化读数： " << sensor_reading << std::endl;

    return 0;
}
