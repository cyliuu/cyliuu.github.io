逐步追踪路线数组

示例工程/main.cpp · 按源码顺序摘录
int num_waypoints = 0;
std::cin >> num_waypoints;
int* route_points = nullptr;
route_points = new int[num_waypoints];
for (int i = 0; i < num_waypoints; ++i) {
    *(route_points + i) = (i + 1) * 10;
}
delete[] route_points;
route_points = nullptr;
网页把输入限定为 1～8 以便观察；原源码没有验证输入数量。new[] 与 delete[] 配对，不能改用 free 释放；持有动态数组的对象还需在复制和析构时明确所有权。
