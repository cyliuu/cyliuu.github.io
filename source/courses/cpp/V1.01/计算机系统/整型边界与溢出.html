C++ 运算规则核对

本区读取上方表盘的当前数据，用独立的加法代码核对 C++ 类型规则。

有符号与无符号加法
int a = 2147483647;
int sum = a + 1;
// 若 int 为 32 位，数学和超出 int 范围；
// 标准 C++ 对这次有符号加法不规定结果。

unsigned char byte = 250;
byte = static_cast<unsigned char>(byte + 10);
// 若 unsigned char 为 8 位，赋值转换后的值为 4。
char 与 int 相加
char letter = 'B';
int offset = 2;
char next = static_cast<char>(letter + offset);
// char 参与加法时通常先提升为 int；赋值时再转回 char。
// 在 ASCII 字符编码中，'B' + 2 对应 'D'。
