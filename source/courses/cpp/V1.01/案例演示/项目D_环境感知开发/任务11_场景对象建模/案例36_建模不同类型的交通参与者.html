情境背景

在对真实交通环境进行软件建模时，我们需要处理多种不同类型的参与者：除了车辆，还包含行人、骑行者，甚至静态的路锥等。这些参与者虽然都是“物体”，但各自拥有独特的属性：车辆有行驶速度，行人有步行速度，而路锥则是静止的。如果我们为每一种参与者都定义一个独立的结构体，当类型增多时，代码会变得冗杂。更重要的是，在很多场景下，一个物体在某一时刻只能是其中一种类型。为了设计一个既能表示多种类型、又能在内存使用上做到极致高效的统一数据结构，我们需要学习两种新的 C++ 工具：枚举（enum），用于给类型打上清晰的“标签”；以及联合（union），一位节省内存的“空间魔术师”。

案例要求

设计并实现一个名为 TrafficParticipant 的单一数据结构，使其能够灵活地表示不同类型的交通参与者，并做到内存使用最优化。定义类型：使用 enum class 定义一个 ObjectType，包含 VEHICLE（车辆）、PEDESTRIAN（行人）、CYCLIST（骑行者）三种类型。定义数据：所有参与者都有一个 int id;，车辆有 float speed;（行驶速度），行人有 float walking_speed;（步行速度），骑行者有 float cycling_speed;（骑行速度）。核心要求是，使用 union 来存储上述三种不同的速度值（因为一个参与者在同一时刻只会有一种速度），然后将 ObjectType 和这个 union 组合在一个 struct 中。在 main 函数中创建至少两个 TrafficParticipant 变量（例如一个车辆和一个行人），分别为它们设置类型和对应的特定数据，并打印出来。
源码核对重点：union 共用存储；标签说明当前实际存放的类型，读取错误成员可能产生无效语义或未定义行为。

// 结合enum, union, struct 建模不同类型的交通参与者

#include <iostream>
#include <string>

// 使用 enum class 定义一个强类型的枚举 ObjectType
//    它为不同的参与者类型提供了清晰、安全的名称
enum class ObjectType {
    VEHICLE,
    PEDESTRIAN,
    CYCLIST
};

// 使用 union 定义一个数据联合 ParticipantData
//    它的所有成员共享同一块内存空间
union ParticipantData {
    float speed;
    float walking_speed;
    float cycling_speed;
};

// 使用 struct 定义最终的交通参与者结构
//    它将类型标签(type)和共享的数据(data_union)聚合在一起
struct TrafficParticipant {
    int id;
    ObjectType type;
    ParticipantData data_union;
};

int main() {
    // 创建并初始化一个车辆对象
    TrafficParticipant vehicle;
    vehicle.id = 101;
    // 记录交通参与者的类型
    vehicle.type = ObjectType::VEHICLE;
    // 根据类型给 union 中对应的成员赋值
    vehicle.data_union.speed = 88.5f;

    // 创建并初始化一个行人对象
    TrafficParticipant pedestrian;
    pedestrian.id = 202;
    pedestrian.type = ObjectType::PEDESTRIAN;
    pedestrian.data_union.walking_speed = 1.2f;

    // 打印信息进行验证
    std::cout << "--- 交通参与者信息 ---" << std::endl;

    // 打印车辆信息
    std::cout << "对象ID: " << vehicle.id << std::endl;
    // 使用 switch (或者 if-else) 来根据类型解释 union 中的数据
    if (vehicle.type == ObjectType::VEHICLE) {
        std::cout << "  类型: 车辆" << std::endl;
        std::cout << "  行驶速度: " << vehicle.data_union.speed << " km/h" << std::endl;
    }

    std::cout << "------------------------" << std::endl;

    // 打印行人信息
    std::cout << "对象ID: " << pedestrian.id << std::endl;
    if (pedestrian.type == ObjectType::PEDESTRIAN) {
        std::cout << "  类型: 行人" << std::endl;
        std::cout << "  步行速度: " << pedestrian.data_union.walking_speed << " m/s" << std::endl;
    }

    return 0;
}
