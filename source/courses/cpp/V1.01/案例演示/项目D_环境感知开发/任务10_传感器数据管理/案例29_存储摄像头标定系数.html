情境背景

在自动驾驶的视觉感知系统中，车载摄像头是获取图像信息的关键传感器。然而，由于摄像头镜头的光学特性，原始图像会存在畸变。为了得到真实世界中物体的准确位置和尺寸，我们必须对图像进行校正。这个校正过程依赖于一组固定的、在摄像头出厂或安装时就已经测量好的内部标定系数。这些系数通常被组织成一个 3x3 的矩阵，称为“内参矩阵”。在程序启动时，需要将这组固定的系数加载到内存中，供后续的图像处理算法使用。数组作为一种存储固定数量、同类型数据的集合，是存储这种标定矩阵最理想、最高效的数据结构。

ee_29/main.cpp
// 使用一维数组存储和访问摄像头的3x3标定矩阵

#include <iostream>
#include <iomanip> // 用于格式化输出

int main() {
    // 定义一个const一维数组来存储固定的标定系数
    //    const 确保了这些重要的参数在程序中不会被意外修改
    //    数据按行优先顺序存放
    const double camera_matrix[] = {
        500.0, 0.0, 320.0,  // 第 0 行
        0.0, 500.0, 240.0,  // 第 1 行
        0.0, 0.0, 1.0       // 第 2 行
    };

    // 通过下标访问数组元素，读取标定参数
    //    - 焦距fx位于第0行第0列，对应数组下标 [0]
    //    - 焦距fy位于第1行第1列，对应数组下标 [4] (3*1 + 1 = 4)
    //    - 光学中心cx位于第0行第2列，对应数组下标 [2]
    //    - 光学中心cy位于第1行第2列，对应数组下标 [5] (3*1 + 2 = 5)
    double fx = camera_matrix[0];
    double fy = camera_matrix[4];
    double cx = camera_matrix[2];
    double cy = camera_matrix[5];

    // 打印提取出的参数，进行验证
    std::cout << "--- 摄像头内部标定参数 ---" << std::endl;
    std::cout << std::fixed << std::setprecision(1); // 设置输出格式
    std::cout << "  - 焦距 (fx): " << fx << " pixels" << std::endl;
    std::cout << "  - 焦距 (fy): " << fy << " pixels" << std::endl;
    std::cout << "  - 光学中心 (cx, cy): (" << cx << ", " << cy << ")" << std::endl;

    return 0;
}
