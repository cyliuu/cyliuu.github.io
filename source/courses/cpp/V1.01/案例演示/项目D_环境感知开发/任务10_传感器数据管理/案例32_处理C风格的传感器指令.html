情境背景

在许多嵌入式系统和一些经典的传感器模块中，为了保持简单和高效，设备间的通信协议可能不使用复杂的格式，而是采用基础的文本指令。例如，一个车载诊断模块或者一个旧式的超声波雷达，可能会通过串口发送和接收简单的、由 ASCII 字符组成的命令。作为一名车载软件工程师，你需要编写一段程序来解析从这样一个传感器传来的指令，程序必须能够准确地识别出特定的命令字符串，以便执行相应的操作。这要求我们掌握 C++ 中处理基础文本数据的方式——C 风格字符串，它本质上就是一个以特殊标记结尾的字符数组。

案例要求

模拟一个指令处理程序，它能接收一个 C 风格的字符串指令，并判断该指令是否为预设的 "QUERY_STATUS"。在 main 函数中，定义一个大小合适的 char 类型数组 command，用于存储用户输入的指令；提示用户输入一个指令字符串；使用 <cstring> 库中提供的专用工具 strcmp 来比较用户输入的字符串和目标字符串 "QUERY_STATUS"；根据比较结果打印出不同的响应信息，例如“状态查询指令已接收”或“未知指令”。
源码核对重点：strcmp 返回 0 恰表示内容相等；返回非零才表示字典序差异。

// 处理C风格的字符串指令

#include <iostream>
#include <cstring> // 必须包含此头文件以使用 strcmp 等C风格字符串工具

int main() {
    // 定义一个字符数组来存储C风格字符串
    //    大小设为50，确保有足够的空间存放指令和结尾的空字符'\0'
    char command[50];

    // 提示并接收用户输入的指令
    std::cout << "请输入传感器指令 (例如 QUERY_STATUS): ";
    // std::cin 会读取一个单词，并在存入 command 数组后自动添加 '\0'
    std::cin >> command;

    // 比较指令字符串
    //    我们不能直接用 command == "QUERY_STATUS" 来比较，
    //    因为那比较的是内存地址，而不是字符串内容
    //    必须使用 strcmp (string compare) 工具
    //    - 如果两个字符串完全相同，strcmp 返回 0
    //    - 如果第一个字符串字典序大于第二个，返回正数
    //    - 如果第一个字符串字典序小于第二个，返回负数
    int compare_result = strcmp(command, "QUERY_STATUS");

    std::cout << "\n--- 指令处理结果 ---" << std::endl;
    // 根据比较结果进行判断
    if (compare_result == 0) {
        std::cout << "状态查询指令 [QUERY_STATUS] 已被识别。" << std::endl;
        std::cout << "正在返回传感器状态..." << std::endl;
    } else {
        std::cout << "接收到未知指令: [" << command << "]" << std::endl;
        std::cout << "无操作被执行。" << std::endl;
    }

    return 0;
}
