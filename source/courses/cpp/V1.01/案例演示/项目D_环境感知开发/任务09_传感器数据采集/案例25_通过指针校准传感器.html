情境背景

在自动驾驶系统中，传感器的精确性至关重要。一个新安装的激光雷达（Lidar）在出厂时带有一个默认的零位偏移量（offset），但在实际装车后，由于安装位置的微小偏差，需要对这个偏移量进行在线校准，以保证测距的绝对准确。在一些底层的嵌入式或高性能计算场景中，传感器的校准参数可能直接映射到内存的特定地址。作为系统工程师，你需要掌握一种能够直接、精确地“定点”修改内存中某个变量值的技术。指针，正是实现这种底层操作最强大、最直接的工具。

案例要求

模拟传感器校准的过程。一个外部传感器的偏移量 offset 在程序中需要被校准。在 main 函数中定义一个浮点型变量 float offset = 0.0f;，代表传感器初始的、未校准的偏移量；定义一个指向浮点型的指针 float* p_offset;；让这个指针指向 offset 变量；不通过变量名 offset，而是通过解引用指针 *p_offset，直接将 offset 的值修改为一个新的校准值，例如 1.25f；最后打印出变量 offset 的值，以验证修改是否成功。
源码核对重点：解引用赋值写入所指对象；指针本身仍保存原对象地址。

ee_25/main.cpp
// 通过指针直接修改内存中的变量值，模拟传感器校准

#include <iostream>

int main() {
    // 在内存中定义一个变量，代表传感器的原始偏移量
    float offset = 0.0f;

    // 打印初始状态
    std::cout << "校准前：" << std::endl;
    std::cout << "  - 变量 offset 的值: " << offset << std::endl;
    // 使用 & 运算符获取 offset 变量在内存中的地址
    std::cout << "  - 变量 offset 的内存地址: " << &offset << std::endl;
    std::cout << "----------------------------------------" << std::endl;

    // 定义一个指针变量 p_offset
    float* p_offset;

    // 将 offset 的地址赋值给指针 p_offset
    //    现在，p_offset 就"指向"了 offset
    p_offset = &offset;

    std::cout << "指针已设置：" << std::endl;
    std::cout << "  - 指针 p_offset 中存储的地址值: " << p_offset << std::endl;
    std::cout << std::endl;

    // 解引用指针并修改传感器偏移量
    //    使用 * (解引用)运算符，访问 p_offset 指向的那块内存，并修改其内容
    std::cout << "正在通过指针 *p_offset 进行校准..." << std::endl;
    *p_offset = 1.25f;
    std::cout << "校准完成！" << std::endl;
    std::cout << "----------------------------------------" << std::endl;

    // 验证结果
    //    再次打印原始变量 offset 的值，会发现它已经被成功修改
    std::cout << "校准后：" << std::endl;
    std::cout << "  - 变量 offset 的值: " << offset << std::endl;

    return 0;
}
