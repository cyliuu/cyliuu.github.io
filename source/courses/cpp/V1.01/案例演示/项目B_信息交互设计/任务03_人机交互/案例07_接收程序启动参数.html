情境背景

实际车载系统中，程序并非总在启动后才等待交互。当你在手机地图选好目的地并发送到汽车时，车载导航程序在启动瞬间就需要接收经纬度信息。这种在程序启动时就传递信息的方式称为“命令行参数”，是专业软件必备的功能。

案例要求

编写程序通过命令行参数接收模拟 GPS 经纬度：./location_tracker 121.47 31.23，识别 121.47 为经度、31.23 为纬度，转换为浮点数后输出“接收到坐标：经度 121.47, 纬度 31.23”；参数不足时给出错误提示。
源码核对重点：argc 包含程序名；源码要求另外两个坐标实参，缺少时先报告用法，不能读取不存在的 argv 元素。

// 读取并处理命令行参数

#include <iostream>
#include <cstdlib> // 包含 atof 函数，将字符串转换为 double

int main(int argc, char* argv[]) {
    // argc 是参数个数（含程序名本身），argv 存放每个参数的字符串内容
    if (argc < 3) {
        std::cout << "错误：参数不足！" << std::endl;
        std::cout << "用法: ./location_tracker [经度] [纬度]" << std::endl;
        return 1; // 返回非零值表示异常退出
    }

    double longitude = atof(argv[1]);
    double latitude = atof(argv[2]);

    std::cout << "接收到坐标：经度 " << longitude << ", 纬度 " << latitude << std::endl;
    return 0;
}
