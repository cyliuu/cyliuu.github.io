情境背景

一个专业的车载数字仪表盘必须以清晰、对齐的格式展示关键信息，任何格式混乱都可能分散驾驶员注意力。仅用 std::cout 手动加空格对齐会非常繁琐。本案例引入源自 C 语言的 printf 函数，教你像“排版师”一样精确控制每个字符和数字的显示位置与格式。

案例要求

定义三个变量：当前车速 88（int）、剩余油量 52.5（double）、当前挡位 'D'（char），用 printf 按“车速： 88 km/h | 油量： 52.5% | 挡位： D”格式输出。
源码核对重点：int 用 %d；double 保留一位小数用 %.1f；%% 才输出字面百分号；char 用 %c。

ee_6/main.cpp
// 使用 printf 函数进行格式化输出

#include <cstdio>

int main() {
    int current_speed = 88;
    double fuel_level = 52.5;
    char current_gear = 'D';

    // %d 整数;%.1f 浮点数保留1位小数;%% 输出百分号;%c 字符;\n 换行
    printf("车速: %d km/h | 油量: %.1f%% | 挡位: %c\n",
           current_speed, fuel_level, current_gear);

    return 0;
}
