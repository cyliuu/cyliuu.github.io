情境背景

在复杂的交通环境中，自动驾驶汽车需要识别和响应各种类型的障碍物，例如其它车辆、行人、路锥等。虽然这些障碍物的具体形态和行为各不相同，但它们共享一些最基本的物理属性，比如在仿真世界中的“位置”。为了高效、系统地管理这些不同但又相关的实体，我们采用面向对象中的“继承”思想，通过设计一个通用的“障碍物”基类来封装所有障碍物共有的属性和行为，然后让具体的障碍物类型继承这个基类。这种“is-a”（是一个）的设计模式，不仅能极大地减少代码重复，更能构建一个清晰、可扩展的对象体系。

案例要求

创建 Obstacle 基类并派生 VehicleObstacle、PedestrianObstacle 以模拟基本障碍物继承体系：基类以 struct Point { double x, y; } 表示位置，提供 protected position、用于初始化位置的公共构造函数及 get_position()；车辆障碍物公有继承基类并增加 double speed，行人障碍物增加 int age。在 main 中分别创建两个派生对象，验证其独有成员和继承来的 get_position()。
源码核对重点：派生对象各自包含基类子对象，可通过继承的接口取得位置；构造时先初始化基类部分。

#include <iostream>

// 用于表示二维坐标的简单结构体
struct Point {
    double x = 0.0;
    double y = 0.0;
};

// 障碍物基类，封装了所有障碍物的共同属性
class Obstacle {
public:
    // 构造函数，用于初始化障碍物位置
    Obstacle(Point pos) : position(pos) {}

    // 公共接口，用于获取障碍物位置
    Point get_position() const {
        return position;
    }

protected:
    // 受保护的成员，可以被派生类访问
    Point position;
};

// 车辆障碍物，继承自Obstacle
class VehicleObstacle : public Obstacle {
public:
    // 派生类的构造函数，通过初始化列表调用基类的构造函数
    VehicleObstacle(Point pos, double spd) : Obstacle(pos), speed(spd) {}

    // 记录车辆速度
    double speed;
};

// 行人障碍物，继承自Obstacle
class PedestrianObstacle : public Obstacle {
public:
    // 派生类的构造函数
    PedestrianObstacle(Point pos, int a) : Obstacle(pos), age(a) {}

    // 记录行人年龄
    int age;
};

int main() {
    // 创建派生类对象
    VehicleObstacle car({50.0, 1.0}, 60.0);
    PedestrianObstacle person({25.0, 0.5}, 30);

    // 验证派生类对象可以调用基类的公共方法
    Point car_pos = car.get_position();
    Point person_pos = person.get_position();

    std::cout << "--- 障碍物信息 ---" << std::endl;

    // 访问各自的成员，并打印信息
    std::cout << "车辆障碍物: "
              << "位置 (" << car_pos.x << ", " << car_pos.y << "), "
              << "速度 " << car.speed << " km/h" << std::endl;

    std::cout << "行人障碍物: "
              << "位置 (" << person_pos.x << ", " << person_pos.y << "), "
              << "年龄 " << person.age << " 岁" << std::endl;

    return 0;
}
