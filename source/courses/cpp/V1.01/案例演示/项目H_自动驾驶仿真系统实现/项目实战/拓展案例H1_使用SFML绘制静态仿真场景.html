情境背景

在复杂的工程与科学计算领域，原始的数据和日志虽然精确，但往往缺乏直观性。仿真是连接理论与现实的桥梁，而一个优秀的图形用户界面（GUI），则是将仿真过程中海量、动态的数据转化为人类能够直观理解和分析的图像的关键。它能让工程师一眼就看出系统的运行状态、潜在问题以及算法的实际效果。从命令行到图形界面，是从“读报告”到“看现场”的飞跃。本案例将是我们进入 GUI 编程世界的第一次实践，我们将学习使用一个强大而简洁的 C++ 多媒体库——SFML，来创建一个真正的窗口，并在其中用图形和文字来“导演”一出静态的场景剧，为后续实现完整、动态的图形化仿真系统打下坚实的基础。

案例要求

编写一个使用 SFML 静态展示简化交通场景的程序：创建标题为 "Static Simulation Scene" 的 800x600 窗口，用绿色 sf::CircleShape 表示主车、红色 sf::RectangleShape 表示前方障碍物，加载字体后以 sf::Text 在左上角显示如“速度：50 km/h”的车辆状态，并在主循环中正确处理关闭窗口事件。
源码核对重点：当前源码建立窗口并绘制两个形状与状态文字，处理关闭事件；页面为结构示意，不伪称浏览器运行了 SFML。

// 使用 SFML 绘制静态道路、车辆与障碍物

#include <SFML/Graphics.hpp>
#include <iostream>
#include <string>

#ifndef FONT_FILE_PATH
#define FONT_FILE_PATH "arial.ttf"
#endif

int main() {
    // 创建仿真窗口
    sf::RenderWindow window(sf::VideoMode(800, 600), "Static Simulation Scene");

    // 绿色圆形表示主车
    sf::CircleShape ego_vehicle(30.f); // 半径为30像素
    ego_vehicle.setFillColor(sf::Color::Green);
    ego_vehicle.setPosition(100.f, 250.f); // 设置在窗口中的位置

    // 红色矩形表示障碍物
    sf::RectangleShape obstacle(sf::Vector2f(50.f, 50.f)); // 50x50像素的正方形
    obstacle.setFillColor(sf::Color::Red);
    obstacle.setPosition(500.f, 250.f);

    // 加载字体并准备状态文本
    sf::Font font;
    if (!font.loadFromFile(FONT_FILE_PATH)) {
        std::cerr << "Error: Could not load font '" << FONT_FILE_PATH
                  << "'" << std::endl;
        return -1;
    }

    sf::Text status_text;
    status_text.setFont(font);
    status_text.setString("速度: 50 km/h\n模式: 自动驾驶");
    status_text.setCharacterSize(24); // 字体大小
    status_text.setFillColor(sf::Color::White);
    status_text.setPosition(10.f, 10.f); // 左上角位置

    // 事件处理与渲染循环
    while (window.isOpen()) {
        sf::Event event;
        while (window.pollEvent(event)) {
            if (event.type == sf::Event::Closed) {
                window.close();
            }
        }

        window.clear(sf::Color(50, 50, 50));

        window.draw(ego_vehicle);
        window.draw(obstacle);
        window.draw(status_text);

        window.display();
    }

    return 0;
}
