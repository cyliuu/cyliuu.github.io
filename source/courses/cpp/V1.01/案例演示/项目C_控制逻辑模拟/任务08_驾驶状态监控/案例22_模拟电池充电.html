情境背景

电动汽车的充电过程并非瞬时完成，而是一个持续不断、状态渐变的过程。在软件开发中，如果想模拟这个过程，让电池电量从一个较低的百分比，一点点地增加到目标值，我们不可能为每一秒的电量变化都写一行代码。这种需要在某个条件满足时，重复执行某个任务的场景，正是循环结构大显身手的舞台。本案例将引导你使用最基础的 while 循环，来模拟电池从开始充电到充满的过程。你将学会如何让程序“等待”并重复执行任务，直到一个特定条件达成，这是构建所有动态仿真的核心基础。

案例要求

编写一个 C++ 程序模拟电池从 20% 充电到 80%：将 double battery_level 初始化为 20.0，在 battery_level < 80.0 时使用 while 循环，每次将电量增加 5.0 并打印当前百分比；达到或超过 80% 后输出“充电完成”。
源码核对重点：while 条件在每轮开始判断；达到阈值后下一次检查为假，结束循环。

// 使用 while 循环模拟电池充电过程

#include <iostream>
#include <iomanip> // 包含 std::fixed 和 std::setprecision

int main() {
    // 初始化电池电量
    double battery_level = 20.0;
    const double TARGET_LEVEL = 80.0;

    std::cout << "--- 电池充电模拟 ---" << std::endl;
    std::cout << "初始电量: " << battery_level << "%" << std::endl;
    std::cout << "充电目标: " << TARGET_LEVEL << "%" << std::endl;
    std::cout << "开始充电..." << std::endl;
    std::cout << "--------------------" << std::endl;

    // 使用 while 循环
    // 每次循环开始前，都会检查括号内的条件 (battery_level < TARGET_LEVEL) 是否为真
    // 如果为真，就执行大括号内的代码;如果为假，就跳过整个循环
    while (battery_level < TARGET_LEVEL) {
        // 在循环体内更新状态
        battery_level += 5.0; // 模拟电量增加 5%

        // 打印当前状态
        std::cout << "当前电量: " 
                  << std::fixed << std::setprecision(1) 
                  << battery_level << "%" << std::endl;
    }

    // 循环结束后的收尾工作
    std::cout << "--------------------" << std::endl;
    std::cout << "已达到充电目标，充电完成。" << std::endl;

    return 0;
}
