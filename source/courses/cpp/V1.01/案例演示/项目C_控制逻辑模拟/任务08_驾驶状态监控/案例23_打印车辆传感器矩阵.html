情境背景

为了理解周围的环境，自动驾驶汽车配备了多种传感器，如毫米波雷达、超声波传感器等。这些传感器的数据可以被整合成一个二维的栅格地图（Grid Map），来表示车辆近处的环境。这个矩阵中的每一个单元格，都可能代表一个小的物理区域，并存储着该区域是否有障碍物的信息。作为一名仿真系统工程师，可视化这些底层数据是调试和验证算法的第一步。你需要编写一个程序，将一个模拟的 4x4 传感器矩阵的状态清晰地打印在控制台上。这个任务无法用单层循环完成，它要求我们掌握循环嵌套的技巧，来处理像表格、矩阵这样的二维数据结构，这是处理多维数据和图像的基础。

案例要求

编写一个 C++ 程序，使用嵌套的 for 循环在控制台打印清晰对齐的 4x4 矩阵；每个元素以其行号和列号组成的 (行,列) 格式表示。
源码核对重点：外层四行、内层每行四列，共 4×4=16 对坐标；内层循环在每次外层迭代中重新开始。

// 使用 嵌套 for 循环来打印一个二维矩阵

#include <iostream>
#include <iomanip> // 包含 setw 用于设置字段宽度，美化输出

int main() {
    // 定义矩阵的维度
    const int NUM_ROWS = 4;
    const int NUM_COLS = 4;

    std::cout << "--- 4x4 传感器矩阵坐标 ---" << std::endl;

    // 外层循环：负责控制"行"
    // 变量 i 代表当前的行号，从 0 增加到 3
    for (int i = 0; i < NUM_ROWS; ++i) {

        // 内层循环：负责控制当前行中的"列"
        // 对于外层循环的每一次迭代（每一行），内层循环都会完整地执行一遍
        // 变量 j 代表当前的列号，从 0 增加到 3
        for (int j = 0; j < NUM_COLS; ++j) {

            // 打印当前(行,列)的坐标
            // setw(7) 设置下一个输出项的宽度为7个字符，用于对齐
            std::cout << std::setw(7) << "(" << i << "," << j << ")";
        }

        // 当前行输出完成后换行
        // 当一行的所有列（内层循环）都打印完毕后，
        // 我们需要打印一个换行符，以便让下一行的内容从新的一行开始
        std::cout << std::endl;
    }

    return 0;
}
