情境背景

在软件开发中，当我们定义一个“类”来描述现实世界的事物时，一个核心问题随之而来：如何保证每一个根据这个类创建出来的“对象”，在它“诞生”的那一刻就处于一个安全、有效的初始状态？例如，一辆新车被“制造”出来时，它的引擎应该是熄火状态，速度应该为 0，油箱或许是满的。如果依赖程序员每次都手动调用一个初始化函数，很容易因遗漏而产生状态不确定的对象，为程序埋下隐患。为了从机制上解决这个问题，C++ 提供了一种特殊的成员函数——构造函数 (Constructor)，它会在对象被创建时自动执行，专门用于初始化。相应地，当一个对象的生命周期结束时，析构函数 (Destructor) 会被自动执行，用于完成必要的清理工作，如释放资源、保存状态等。这两种函数共同构成了对象完整的“生命周期管理”机制，是面向对象编程的基石。

案例要求

为 Vehicle 类添加 private bool is_running，并用构造函数将 speed 初始化为 0.0、is_running 初始化为 false 后输出车辆处于熄火状态的消息；再用析构函数输出对象已销毁的消息。在 main 的不同作用域中创建对象，观察两类函数随对象创建和销毁自动执行的过程。
源码核对重点：自动存储期对象在进入相应作用域构造，离开时按生命周期规则析构；网页只展示顺序，不实际调用 C++ 对象。

// 使用构造函数和析构函数管理车辆对象的生命周期

#include <iostream>

class Vehicle {
public:
    // 构造函数 (Constructor)
    //    - 函数名与类名完全相同
    //    - 没有返回类型
    //    - 在对象创建时自动被调用
    Vehicle() {
        speed = 0.0;
        is_running = false;
        std::cout << "[构造函数]: 一辆新车已创建, 引擎熄火, 速度为 0。" << std::endl;
    }

    // 析构函数 (Destructor)
    //    - 函数名是波浪号(~)后跟类名
    //    - 没有返回类型，也没有参数
    //    - 在对象生命周期结束时（如离开作用域）自动被调用
    ~Vehicle() {
        std::cout << "[析构函数]: 车辆对象生命周期结束, 已被销毁。" << std::endl;
    }

    // 公共成员函数 - 对象的"行为"
    void start_engine() {
        is_running = true;
        std::cout << "[行为]: 引擎已启动。" << std::endl;
    }

    void stop_engine() {
        is_running = false;
        std::cout << "[行为]: 引擎已熄火。" << std::endl;
    }

    // 获取当前速度
    double get_speed() {
        return speed;
    }

    // 获取运行状态
    bool get_is_running() {
        return is_running;
    }

private:
    // 私有数据成员 - 对象的"属性"
    double speed;
    bool is_running;
};

// 程序入口观察对象的创建和销毁
int main() {
    std::cout << "--- main函数开始 ---" << std::endl;

    { // 创建一个新的作用域来观察对象的生命周期
        std::cout << "  -> 进入新的作用域, 准备创建 my_car 对象..." << std::endl;

        // 当这行代码执行时, Vehicle 的构造函数会自动被调用
        Vehicle my_car; 

        // 验证一下初始状态
        std::cout << "  -> 验证初始状态: 车辆运行中? " 
                  << (my_car.get_is_running() ? "是" : "否") << std::endl;

        my_car.start_engine(); // 启动引擎

        std::cout << "  -> 准备离开作用域..." << std::endl;
    } // 当代码执行到这个右花括号, my_car 对象的生命周期结束, 析构函数会自动被调用

    std::cout << "--- main函数结束 ---" << std::endl;

    return 0;
}
