情境背景

在任何复杂的软件系统中，无论是交通模拟、赛车游戏还是物流管理平台，我们都需要用代码来描述和模拟真实世界的实体。车辆（Vehicle）就是一个典型的例子，它既有自身的静态属性（如速度、位置、颜色），也有一系列动态的行为（如加速、刹车、转向）。在程序设计的初级阶段，我们可能会使用结构体（struct）来聚合车辆的各种数据，然而操作这些数据的行为却与数据本身是分离的。这种模式导致代码分散、难以维护，且任何外部代码都能随意修改车辆的关键数据，缺乏安全性。为了解决这些问题，我们需要引入面向对象编程（OOP）的核心思想——封装，将数据和操作数据的行为“打包”成一个权责一体的智能对象。

案例要求

将一个基于 struct 和全局函数的简化车辆表示法重构为封装良好的 Vehicle 类：把 speed、position 等数据迁移为 private 属性，将操作数据的全局函数改为 public 成员函数（如 accelerate()），并在 main 中创建对象、通过公共接口修改和显示车辆状态。
源码核对重点：private 限制外部直接访问，public 成员函数是受控接口；get_speed 负责读取状态。

// 从struct到class，设计第一个"车辆"类

#include <iostream>

// 我们要重构的 Vehicle 类
class Vehicle {
// public 访问说明符：定义了类的"公共接口"
//    外部代码可以通过这些接口与对象交互
public:
    // 公共成员函数 - 对象的"行为"

    // 加速（行为）
    void accelerate() {
        // 成员函数可以直接访问同一个类的私有成员
        if (speed < 120.0) {
            speed += 5.0;
        }
    }

    // 减速（行为）
    void brake() {
        if (speed > 0.0) {
            speed -= 5.0;
        }
    }

    // 获取当前速度（行为） - 用于从外部安全地读取私有数据
    double get_speed() {
        return speed;
    }

    // 设置车辆的初始状态（行为）
    void set_initial_state(double initial_speed) {
        speed = initial_speed;
    }

// private 访问说明符：定义了类的"内部数据"
//    这些数据被保护起来，只能被本类的成员函数访问
private:
    // 私有数据成员 - 对象的"属性"
    double speed;       // 车速 (km/h)
    double position;    // 位置 (m)
};

// 程序入口使用 Vehicle 对象
int main() {
    // 创建一个 Vehicle 类的对象（实例），名为 my_car
    Vehicle my_car;

    // 通过公共接口（成员函数）来初始化和操作对象
    my_car.set_initial_state(60.0);
    std::cout << "初始车速: " << my_car.get_speed() << " km/h" << std::endl;

    my_car.accelerate(); // 调用加速行为
    std::cout << "加速后车速: " << my_car.get_speed() << " km/h" << std::endl;

    my_car.brake(); // 调用减速行为
    my_car.brake();
    std::cout << "连续两次减速后车速: " << my_car.get_speed() << " km/h" << std::endl;

    // 尝试从外部直接访问私有成员，将会导致编译失败
    // my_car.speed = 200.0; // <- 如果取消这行注释，编译器会报错！
    // 错误信息: 'double Vehicle::speed' is private

    return 0;
}
