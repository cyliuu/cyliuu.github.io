情境背景

在我们设计一个“类”时，就如同在设计一个精密的电子设备。这个设备会向用户暴露一些必要的按钮、开关和显示屏（公共接口），但会把内部复杂的电路板、芯片和高压线路用外壳保护起来（内部实现）。这种“内外有别”的设计思想至关重要：它不仅能防止用户因误操作而损坏设备，还能让设计者在未来自由地升级内部零件，而无需改变用户的使用习惯。在 C++ 中，实现这种“封装”和“保护”的机制就是访问说明符（public、private、protected）。一个设计良好的类，应该只对外暴露“做什么”的接口，而将“怎么做”的实现细节和核心数据隐藏起来。如果不加以区分，所有成员都可被外部随意访问，类就退化成了一个普通的结构体，失去了面向对象编程的核心优势。

案例要求

使用 public 和 private 改造 Vehicle 类以保护核心数据和内部实现：类包含 const int id、double engine_temperature、accelerate()、get_speed() 与内部辅助函数 update_engine_temp()，仅将公共接口暴露给外部。在 main 中通过公共接口与对象交互，并用注释标出直接访问私有成员会导致编译错误的代码。
源码核对重点：封装隐藏内部表示，通过 public 接口约束更新；const ID 还应在构造初始化阶段确定。

// 使用 public 和 private 封装车辆数据

#include <iostream>

class Vehicle {
// public 成员：类的公共接口，供外部代码与对象交互
public:
    // 构造函数通常是 public 的，以便能创建对象
    Vehicle(int vehicle_id) : id(vehicle_id), speed(0.0), engine_temperature(25.0) {
        std::cout << "ID为 " << id << " 的车辆已创建。" << std::endl;
    }

    // 公共行为接口：加速
    void accelerate() {
        if (speed < 120.0) {
            speed += 10.0;
            // 调用私有的辅助函数来更新内部状态
            update_engine_temp(); 
        }
        std::cout << "车辆正在加速... 当前速度: " << speed << " km/h" << std::endl;
    }

    // 公共数据接口：安全地获取速度
    double get_speed() const {
        return speed;
    }

    // 公共数据接口：安全地获取引擎温度
    double get_engine_temperature() const {
        return engine_temperature;
    }

// private 成员：类的内部实现，只能由本类成员函数访问
private:
    // 私有核心数据
    const int id;             // 车辆的唯一ID，const确保其不可变
    double speed;             // 当前速度
    double engine_temperature;// 引擎温度

    // 私有辅助函数，属于内部实现细节
    void update_engine_temp() {
        engine_temperature += 5.0; // 每次加速，温度升高
    }
};

// 程序入口通过 Vehicle 的公共接口展示封装
int main() {
    // 创建一个 Vehicle 对象，ID为 2024
    Vehicle my_car(2024);

    // 通过 public 接口与对象交互，这是正确的、安全的方式
    std::cout << "初始引擎温度: " << my_car.get_engine_temperature() << " C" << std::endl;
    my_car.accelerate();
    my_car.accelerate();
    std::cout << "加速后引擎温度: " << my_car.get_engine_temperature() << " C" << std::endl;

    // 尝试从外部直接访问 private 成员，将导致编译失败！
    // my_car.speed = 200.0;             // 错误: 'double Vehicle::speed' is private
    // my_car.update_engine_temp();    // 错误: 'void Vehicle::update_engine_temp()' is private
    // std::cout << my_car.id;          // 错误: 'const int Vehicle::id' is private

    std::cout << "\n演示结束。以上被注释的代码如果取消注释，程序将无法通过编译。" << std::endl;

    return 0;
}
