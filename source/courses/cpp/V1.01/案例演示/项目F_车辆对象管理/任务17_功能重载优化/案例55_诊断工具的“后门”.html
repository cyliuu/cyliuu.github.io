情境背景

面向对象编程的核心思想之一是“封装”，即通过 private 关键字将类的核心数据和实现细节保护起来，防止外部代码的非法访问和修改。然而，在某些特殊情况下，这种严格的隔离会带来不便。例如，汽车制造商需要为车辆提供一个诊断工具，这个工具在检修时必须能够直接读取甚至修改引擎内部的私有状态码（如故障码），但我们又不希望将这些敏感数据对所有普通用户（代码）公开。为了解决这种“既要保护数据，又要为特定外部功能开放一个受控‘后门’”的矛盾需求，C++ 提供了 friend（友元）机制。通过将一个外部函数或整个外部类声明为某个类的“友元”，我们就赋予了它直接访问该类所有 private 和 protected 成员的特权。友元机制是在不破坏整体封装性的前提下，为类之间紧密的协作提供的一条合法通道。

案例要求

本案例分为两个任务，旨在掌握友元函数和友元类的使用。 （1）友元函数：模拟一个外部诊断函数读取车辆私有故障码的场景。创建一个 Vehicle 类，包含一个私有的 int 类型成员 engine_fault_code_；在类外部定义一个全局函数 run_vehicle_diagnostics(const Vehicle& vehicle)；在 Vehicle 类内部使用 friend 关键字将其声明为友元函数；在 main 函数中创建一个 Vehicle 对象并调用友元函数来读取并打印其私有的故障码。 （2）友元类：模拟一个专业的诊断工具类，需要全面访问车辆的内部状态。创建一个 Vehicle 类，包含多个私有成员如 engine_fault_code_ 和 mileage_；另外创建一个 DiagnosticTool 类；在 Vehicle 类内部使用 friend class 关键字将整个 DiagnosticTool 类声明为友元类；在 DiagnosticTool 类中实现一个成员函数 perform_full_scan(Vehicle& vehicle)，读取车辆的故障码并重置其里程数。
源码核对重点：友元授权是显式、定向的；两个 variant 展示函数友元与类友元，不能据此认为类的封装完全失效。

// 使用 friend 函数访问私有成员

#include <iostream>

class Vehicle {
public:
    Vehicle(int fault_code) : engine_fault_code_(fault_code) {}

private:
    int engine_fault_code_;

    // 声明外部函数 run_vehicle_diagnostics 是本类的友元
    //    这给予了该函数访问 Vehicle 所有成员的权限
    friend void run_vehicle_diagnostics(const Vehicle& vehicle);
};

// 友元函数的定义（在类的外部）
//    注意：这里没有 Vehicle:: 前缀，因为它是一个全局函数，不是成员函数
void run_vehicle_diagnostics(const Vehicle& vehicle) {
    std::cout << "[诊断工具]: 正在通过友元函数访问..." << std::endl;
    // 直接访问 Vehicle 的私有成员 engine_fault_code_
    if (vehicle.engine_fault_code_ == 0) {
        std::cout << "  -> 诊断结果: 引擎状态正常。" << std::endl;
    } else {
        std::cout << "  -> 检测到故障! 故障码: " << vehicle.engine_fault_code_ << std::endl;
    }
}

int main() {
    Vehicle my_car(404); // 创建一辆带有故障码的汽车

    // 调用全局的友元函数，对 my_car 对象进行诊断
    run_vehicle_diagnostics(my_car);

    return 0;
}

// 使用 friend 类访问私有成员

#include <iostream>

// 需要前向声明 Vehicle 类, 因为 DiagnosticTool 的成员函数参数会用到它
class Vehicle; 

// 诊断工具类
class DiagnosticTool {
public:
    void perform_full_scan(Vehicle& vehicle); // 成员函数声明
};

// 车辆类
class Vehicle {
public:
    Vehicle(int fault_code, double initial_mileage) 
        : engine_fault_code_(fault_code), mileage_(initial_mileage) {}

    void display() const {
        std::cout << "  -> 车辆当前状态 | 故障码: " << engine_fault_code_ 
                  << ", 里程: " << mileage_ << " km" << std::endl;
    }

private:
    int engine_fault_code_;
    double mileage_;

    // 声明 DiagnosticTool 整个类是本类的友元
    //    这意味着 DiagnosticTool 的所有成员函数都可以访问 Vehicle 的私有成员
    friend class DiagnosticTool;
};

// DiagnosticTool 成员函数的实现
// 必须在 Vehicle 类的完整定义之后
void DiagnosticTool::perform_full_scan(Vehicle& vehicle) {
    std::cout << "[诊断工具]: 正在通过友元类进行深度扫描..." << std::endl;

    // 直接访问 Vehicle 的私有成员
    std::cout << "  -> 读取到故障码: " << vehicle.engine_fault_code_ << std::endl;

    std::cout << "  -> 检测到里程数: " << vehicle.mileage_ << std::endl;
    std::cout << "  -> 正在执行保养操作: 重置里程数..." << std::endl;

    // 甚至可以修改 Vehicle 的私有成员
    vehicle.mileage_ = 0; 
}

int main() {
    Vehicle my_car(501, 15000.5);
    DiagnosticTool technician_tool;

    std::cout << "保养前:" << std::endl;
    my_car.display();

    // 使用诊断工具对车辆进行扫描和操作
    technician_tool.perform_full_scan(my_car);

    std::cout << "\n保养后:" << std::endl;
    my_car.display();

    return 0;
}
