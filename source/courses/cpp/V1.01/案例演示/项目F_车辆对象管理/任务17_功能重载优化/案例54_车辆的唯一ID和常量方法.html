情境背景

在设计一个“类”时，我们常需要处理两种特殊的属性：一种是属于对象个体且不可变的，例如每辆车出厂时就被赋予的独一无二的车辆识别码（VIN），它在车辆的整个生命周期中都不能被更改；另一种是属于整个类而非某个特定对象的，例如一个汽车工厂需要统计总共生产了多少辆车，这个“总产量”数据是所有车辆对象所共享的。为了满足这两种需求，C++ 提供了 const 和 static 两种关键字。const 成员用于确保对象数据的恒定性，而 static 成员则用于实现类级别的共享数据；同时，为了保证代码的健壮性，我们还需要提供安全的“只读”方法（const 成员函数），确保它们在被调用时不会意外修改对象状态。本案例将结合这两种成员，来构建一个信息更完备、设计更安全的 Vehicle 类。

案例要求

设计一个同时使用 const 和 static 成员的 Vehicle 类：以 const int VIN 保存唯一识别码、以 private static int vehicle_count 跟踪存活对象数；构造函数通过初始化列表设置 VIN 并递增计数，析构函数递减计数，const 的 display() 输出车辆信息，静态 get_vehicle_count() 供外部读取总数。在 main 中创建多个对象（含一个 const 对象）并观察总数变化。
源码核对重点：const 成员函数限制通过该接口修改普通成员；static 计数器属于类级共享状态，并随对象创建/销毁变化。

// 结合 const 和 static 成员管理车辆信息

#include <iostream>

class Vehicle {
public:
    // 构造函数
    //    - const 成员 'VIN' 必须在成员初始化列表中进行初始化
    Vehicle(int vin) : VIN(vin) {
        vehicle_count++; // 每创建一个对象, 静态计数器加一
        std::cout << "[构造] VIN: " << VIN << " 的车辆已创建。";
        std::cout << "当前车辆总数: " << vehicle_count << std::endl;
    }

    // 析构函数
    ~Vehicle() {
        vehicle_count--; // 每销毁一个对象, 静态计数器减一
        std::cout << "[析构] VIN: " << VIN << " 的车辆已销毁。";
        std::cout << "当前车辆总数: " << vehicle_count << std::endl;
    }

    // 常量成员函数: 承诺不修改任何成员变量
    void display() const {
        std::cout << "  -> 车辆信息 | VIN: " << VIN << std::endl;
    }

    // 静态成员函数: 属于类, 不属于任何特定对象
    //    它只能访问静态成员
    static int get_vehicle_count() {
        return vehicle_count;
    }

private:
    // const 成员: 每个对象都有一份, 但初始化后不可更改
    const int VIN; 

    // static 成员: 所有对象共享一份
    static int vehicle_count; 
};

// 静态数据成员必须在类定义的外部进行初始化
int Vehicle::vehicle_count = 0;

// 程序入口展示 const 和 static 成员的使用
int main() {
    std::cout << "程序开始时, 车辆总数: " << Vehicle::get_vehicle_count() << std::endl;

    std::cout << "\n--- 创建两辆车 ---" << std::endl;
    Vehicle car1(101);
    Vehicle car2(102);

    std::cout << "\n--- 进入一个新的作用域 ---" << std::endl;
    {
        const Vehicle car3_const(103); // 创建一个常量对象
        std::cout << "在作用域内部, 车辆总数: " << Vehicle::get_vehicle_count() << std::endl;

        car3_const.display(); // OK: const 对象可以调用 const 成员函数
        // car3_const.VIN = 104; // 错误: const 成员不能被修改
    } // car3_const 在这里被销毁

    std::cout << "\n--- 离开作用域后 ---" << std::endl;
    std::cout << "程序即将结束, 车辆总数: " << car1.get_vehicle_count() << std::endl; // 也可以通过对象调用静态函数

    return 0;
} // car1 和 car2 在这里被销毁
