情境背景

在自动驾驶系统中，车辆必须严格遵守其所在道路的速度限制。这些限制信息通常由高精地图模块或视觉感知模块（通过识别限速标志）提供。一个典型的需求是，决策模块需要向地图模块查询当前路段的最低和最高允许车速，以便规划自己的行驶速度。这就带来了一个常见的编程问题：一个函数在设计上只能有一个直接的返回值，但我们现在需要它同时“返回”两个值（最低车速和最高车速）。直接返回一个 struct 或 std::pair 是一种方法，但在很多追求性能和灵活性的场景下，使用输出参数是一种更高效、更通用的 C++ 编程范式。本案例将引导我们学习如何通过引用参数来巧妙地实现“返回”多个值的效果。

案例要求

编写一个函数 get_speed_limits，它模拟从地图模块获取速度限制的过程。该函数不使用 return 语句来返回速度值，而是通过引用参数将获取到的最低和最高车速“传出”给调用者。创建一个名为 get_speed_limits 的函数；该函数的返回类型应为 bool，用于表示操作是否成功（例如，true 表示成功获取到速度限制，false 表示该路段无限制信息）；该函数接收两个引用参数：int& min_speed_out 和 int& max_speed_out，这两个参数将作为“输出通道”；函数体内，模拟成功获取到数据，为这两个引用参数赋值（例如，最低速为 30，最高速为 120）；在 main 函数中，定义两个普通整型变量，将它们传递给 get_speed_limits 函数，然后检查函数的 bool 返回值，如果为 true，则打印出这两个已被函数修改过的变量的值。
源码核对重点：返回值表示获取是否成功；引用形参承担额外输出通道，调用者原变量被写入 30 和 120。

ee_43/main.cpp
// 通过引用参数"返回"多个值

#include <iostream>

// 函数定义
// 功能： 模拟获取当前路段的速度限制
// 返回： bool - true表示成功获取，false表示失败
// 参数：
//   - min_speed_out: (输出参数) 用于接收最低限速的引用
//   - max_speed_out: (输出参数) 用于接收最高限速的引用
bool get_speed_limits(int& min_speed_out, int& max_speed_out) {
    // 模拟从地图模块查询到的数据
    const bool found_limits = true;

    if (found_limits) {
        // 通过引用，直接修改了 main 函数中传入的变量
        min_speed_out = 30;
        max_speed_out = 120;
        return true; // 返回成功状态
    } else {
        // 如果查询失败，不修改输出参数，并返回失败状态
        return false;
    }
}

int main() {
    // 在main函数中定义两个变量，用于接收函数的"输出"
    int min_limit = 0;
    int max_limit = 0;

    std::cout << "--- 速度限制查询 ---" << std::endl;
    std::cout << "调用函数前： min_limit = " << min_limit 
              << ", max_limit = " << max_limit << std::endl;

    // 调用函数，并将变量的引用传递进去
    if (get_speed_limits(min_limit, max_limit)) {
        std::cout << "成功获取到速度限制！" << std::endl;
        std::cout << "调用函数后： min_limit = " << min_limit 
                  << ", max_limit = " << max_limit << std::endl;
    } else {
        std::cout << "未能获取到当前路段的速度限制。" << std::endl;
    }

    return 0;
}
