案例任务与源码核对

情境背景

在开发复杂的自动驾驶决策系统时，日志系统是不可或缺的调试和分析工具。工程师需要实时地打印出车辆的决策过程，以便追踪其行为逻辑，例如“检测到前方障碍物，开始减速”、“左侧车道安全，准备变道”等。在不同的调试阶段，我们对日志的详细程度有不同的需求：有时只需要一条简单的信息，而在关键调试环节，我们可能希望为这条信息附加一个“优先级”或“重要性”等级（例如，0 代表紧急，1 代表普通，2 代表信息）。如果为此设计两个函数，如 log(string) 和 logWithPriority(string, int)，会显得很笨拙。我们希望用一个统一的 log 函数接口，使其既能处理简单的日志记录，又能处理带优先级的日志。默认实参正是为实现这种灵活性而设计的。

案例要求

编写一个名为 log_decision 的日志打印函数，它利用默认实参来实现参数的可选性，使函数调用更加灵活。创建一个 log_decision 函数，其返回类型为 void；该函数接收两个参数：const std::string& decision（需要打印的决策内容）、int priority（日志的优先级等级）；为参数 priority 设置一个默认值 1，代表“普通”级别；函数体内，根据不同的优先级，打印出带有不同前缀的日志信息，例如优先级 0 为 [URGENT]，优先级 1 为 [INFO]；在 main 函数中，以两种不同的方式调用 log_decision 函数：一次只提供决策内容，让 priority 参数使用其默认值；另一次同时提供决策内容和一个自定义的优先级（如 0），以覆盖默认值。
源码核对重点：默认实参仅在调用方未提供参数时使用；显式 0 覆盖默认值。

// 使用默认实参，设计一个灵活的决策日志打印函数

#include <iostream>
#include <string>

// 函数声明与定义
// 功能： 打印一条决策日志
// 参数：
//   - decision: 决策的具体内容
//   - priority: 日志的优先级，默认值为1 (普通)
void log_decision(const std::string& decision, int priority = 1) {
    std::cout << "决策日志： ";

    // 根据不同的优先级，添加不同的前缀
    switch (priority) {
        case 0:
            std::cout << "[URGENT] ";
            break;
        case 1:
            std::cout << "[INFO] ";
            break;
        default:
            std::cout << "[DEBUG] ";
            break;
    }

    std::cout << decision << std::endl;
}

int main() {
    std::cout << "--- 自动驾驶决策日志 ---" << std::endl;

    // 调用方式 1：只提供第一个参数
    //    此时，priority参数会自动使用其默认值 1
    log_decision("前方畅通，保持当前速度巡航");

    // 调用方式 2：提供所有参数
    //    此时，我们传入的 0 会覆盖掉 priority 的默认值
    log_decision("检测到前方行人，执行紧急制动！",  0);

    return 0;
}
