案例背景

随着一个车载应用的功能逐渐丰富，main 函数不可避免地变得越来越长，各种逻辑都混杂在一起。这种“一锅烩”的写法导致代码可读性差、难以维护，并且任何一处微小的修改都可能牵一发而动全身，这在软件工程中是不可持续的。为了解决这个问题，我们需要引入一种更专业的设计思想——面向过程设计。其核心就是“分而治之”，将一个庞大的任务分解成一系列职责单一、逻辑清晰的步骤，并将每个步骤封装成独立的函数。在本案例中，你将扮演一名“系统设计师”，借助 AIGC 的力量，为一个典型的核心算法逻辑——例如智能巡航控制中的速度决策，生成第一个独立的函数模块。

任务要求

使用 AIGC 工具，根据功能描述，生成一个用于计算自适应巡航目标速度的核心 C++ 函数。向任意一款 AIGC 工具，用自然语言清晰地描述一个核心的 ACC 算法规则；你的描述必须包含函数的名称（calculate_target_speed）、输入参数（当前速度、前车距离）和明确的、分段的计算逻辑；要求 AIGC 为你生成一个完整的、符合 C++ 语法的、可直接运行的函数代码；分析 AIGC 生成的代码，理解它是如何将你的自然语言描述，转化为结构化的程序逻辑的。输入给 AIGC 的提示（Prompt）如下：
> 我需要你扮演一名专业的 C++ 软件工程师。请为我编写一个用于自动驾驶自适应巡航控制的核心功能函数。函数要求如下：函数名为 calculate_target_speed；它接收两个 double 类型的参数 current_speed（当前车速，km/h）和 distance_to_front_car（与前车的距离，m）；它返回一个 double 类型的目标车速（km/h）。函数内部的逻辑如下：如果与前车的距离大于 100 米，则目标速度为最高限速 120 km/h；如果距离在 50 米到 100 米之间（含边界），则目标速度为保持当前速度不变；如果距离小于 50 米，则目标速度为当前速度的 80%（乘以 0.8），以进行减速。请生成完整的、包含必要头文件和注释的 C++ 函数代码。

[提示] 本案例包含后续将学习的函数、参数和返回值等内容。此时不要求逐行解释代码，重点观察一个完整功能被独立封装后的代码形态。

案例原始资料

以下为案例的提示、代码与运行分析；其中展示的 AIGC 输出不是本网页实时生成。

案例代码、提示与输入
#include <iostream>

/**
 * @brief 根据与前车的距离计算自适应巡航的目标速度
 * * @param current_speed 当前车速 (km/h)
 * @param distance_to_front_car 与前方车辆的距离 (m)
 * @return double 计算出的目标车速 (km/h)
 */
double calculate_target_speed(double current_speed, double distance_to_front_car) {
    const double MAX_SPEED = 120.0;

    if (distance_to_front_car > 100.0) {
        // 距离安全，可以加速到最高限速
        return MAX_SPEED;
    } else if (distance_to_front_car >= 50.0) {
        // 距离适中，保持当前速度跟车
        return current_speed;
    } else {
        // 距离过近，需要减速，目标速度为当前速度的80%
        return current_speed * 0.8;
    }
}

// 用于测试的 main 函数
int main() {
    std::cout << "测试场景1 (远距离): " 
              << calculate_target_speed(80.0, 150.0) << " km/h" << std::endl;

    std::cout << "测试场景2 (跟车距离): " 
              << calculate_target_speed(90.0, 75.0) << " km/h" << std::endl;

    std::cout << "测试场景3 (近距离): " 
              << calculate_target_speed(100.0, 40.0) << " km/h" << std::endl;

    return 0;
}

AIGC 准确地理解了我们的自然语言需求，并将其转化为了一个结构清晰、逻辑正确的 C++ 函数；if-else if-else 结构完美地对应了我们描述的三种分段逻辑；这个函数是自包含的，它封装了单一的职责（计算目标速度），可以被项目中的任何其他部分轻松调用，这正是面向过程设计中“功能分解”思想的体现。
