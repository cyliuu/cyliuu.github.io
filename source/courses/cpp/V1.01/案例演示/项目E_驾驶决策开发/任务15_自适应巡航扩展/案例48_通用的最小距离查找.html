情境背景

在自适应巡航控制（ACC）和前向碰撞预警（FCW）系统中，一个最基础且最高频的操作就是从多个传感器目标中，找出距离本车最近的那一个。这个“查找最小距离”的逻辑，无论是在处理来自激光雷达的 double 类型高精度距离数据，还是在处理来自毫米波雷达的 float 类型数据，甚至是处理来自内部计算模块的 int 类型栅格距离，其核心的比较算法是完全相同的。如果我们为每一种数据类型都编写一个独立的 find_min_distance 重载函数，将会产生大量的冗余代码，这不仅增加了维护成本，也违背了“Don't Repeat Yourself (DRY)”的编程原则。函数模板为此提供了终极解决方案，它允许我们只编写一次比较逻辑，就能创建一个通用的“模具”，由编译器在编译时自动为所有需要的数据类型生成最高效的定制化函数。

案例要求

编写一个名为 find_closest 的函数模板，使其能够通用地比较任意两个数值类型的大小，并返回较小的那一个。使用 template <typename T> 语法，定义一个名为 find_closest 的函数模板；该模板函数接收两个 T 类型的参数，并返回一个 T 类型的值；函数体内的逻辑非常简单：使用三元运算符 ? : 比较两个参数并返回较小者；在 main 函数中，必须用至少三种不同的数值类型（例如 int、float、double）来调用 find_closest 函数，以充分验证其泛型能力；在代码注释中，解释编译器是如何根据调用时的参数类型，隐式地实例化出不同版本的模板函数的。
源码核对重点：函数模板让同一算法作用于不同类型；实际实例化和可用运算由编译器根据调用类型确定。

// 使用函数模板实现通用的最小距离查找

#include <iostream>

// 定义函数模板
//    template <typename T> 告诉编译器，这是一个模板，T是一个类型的占位符
//    这个模板可以用于任何支持 '>' 运算符的类型 T
template <typename T>
T find_closest(T dist1, T dist2) {
    // 对所有 T 类型采用相同的比较逻辑
    return (dist1 < dist2) ? dist1 : dist2;
}

int main() {
    std::cout << "--- 通用最小距离查找器 ---" << std::endl;

    // 使用整数距离实例化函数模板
    int grid_dist1 = 50;
    int grid_dist2 = 35;
    // 调用时，编译器看到两个int参数，会自动推导 T 为 int，
    // 并"实例化"出一个 int find_closest(int, int) 函数
    int closest_grid_dist = find_closest(grid_dist1, grid_dist2);
    std::cout << "整数距离 " << grid_dist1 << "m 和 " << grid_dist2 
              << "m 中，较近的是： " << closest_grid_dist << "m" << std::endl;

    // 使用浮点距离实例化函数模板
    float radar_dist1 = 42.5f;
    float radar_dist2 = 42.8f;
    // 调用时，编译器看到两个float参数，会自动推导 T 为 float，
    // 并实例化出一个 float find_closest(float, float) 函数
    float closest_radar_dist = find_closest(radar_dist1, radar_dist2);
    std::cout << "浮点数距离 " << radar_dist1 << "m 和 " << radar_dist2 
              << "m 中，较近的是： " << closest_radar_dist << "m" << std::endl;

    // 使用双精度距离实例化函数模板
    double lidar_dist1 = 88.12345;
    double lidar_dist2 = 88.12354;
    // 调用时，编译器看到两个double参数，会自动推导 T 为 double，
    // 并实例化出一个 double find_closest(double, double) 函数
    double closest_lidar_dist = find_closest(lidar_dist1, lidar_dist2);
    std::cout << "双精度距离 " << lidar_dist1 << "m 和 " << lidar_dist2 
              << "m 中，较近的是： " << closest_lidar_dist << "m" << std::endl;

    return 0;
}
