情境背景

虽然创建自己的库是一项关键技能，但在真实的软件工程世界里，我们更多时候是“使用工具”的专家。现代 C++ 生态系统拥有海量优秀的开源第三方库，它们提供了从配置文件解析到网络通信等各种成熟的解决方案，让我们不必“重复造轮子”，可以站在巨人的肩膀上，专注于实现自己独特的核心业务逻辑。本案例将模拟一个在车载软件开发中极为常见的场景：程序有许多可调参数（如最高速度、车道宽度等），但它们都硬编码在代码中。为了让程序更灵活，我们需要将这些配置项移到一个外部的 .ini 文件中。我们将学习如何获取一个专业的第三方 INI 解析库，并将其链接到我们的项目中，从而用工业级的方法来读取配置文件。

案例要求

学习并实践在一个 CMake 项目中，链接并使用一个外部的、开源的第三方库。我们将选用一个非常轻量级的 INI 文件解析库——inih 作为示例。获取库：从 inih 的 GitHub 仓库下载其源代码，由于它非常简单，我们只需要 ini.h、ini.c（或 cpp 版本）和 INIReader.h、INIReader.cpp 这几个核心文件；项目结构：创建一个清晰的项目结构，将第三方库的源码放在一个独立的 external 或 third_party 目录中；配置文件：创建一个 config.ini 文件，在其中定义车辆的配置参数；主程序：编写 main.cpp，使用 inih 库提供的 INIReader 类来读取 config.ini 中的配置项；CMake 配置：编写 CMakeLists.txt，这是本案例的核心，你需要学会如何告诉 CMake：在哪里可以找到第三方库的头文件、如何将第三方库的源文件和你的主程序一起编译和链接。
源码核对重点：INIReader 读取文件失败需要报告；文件可读但某键不存在时，Get 系列可使用源码给出的默认值。

eee_E2/main.cpp
// 链接并使用 inih 库来读取配置文件

#include <iostream>
#include "external/inih/cpp/INIReader.h" // 包含第三方库的头文件

#ifndef CONFIG_FILE_PATH
#define CONFIG_FILE_PATH "config.ini"
#endif

int main() {
    // 创建 INIReader 对象，并加载配置文件
    INIReader reader(CONFIG_FILE_PATH);

    // 检查文件是否加载成功
    if (reader.ParseError() < 0) {
        std::cout << "无法加载 'config.ini'\n";
        return 1;
    }

    // 使用库提供的API读取配置项
    //    GetReal(section, name, default_value)
    double max_speed = reader.GetReal("DriverAssist", "max_speed", 80.0);
    //    GetBoolean(section, name, default_value)
    bool lane_change = reader.GetBoolean("DriverAssist", "lane_change_enabled", false);
    //    GetInteger(section, name, default_value)
    long duration = reader.GetInteger("Simulation", "duration_s", 30);

    // 打印读取到的配置
    std::cout << "--- 仿真配置加载成功 ---" << std::endl;
    std::cout << "最高速度： " << max_speed << " km/h" << std::endl;
    std::cout << "允许自动变道： " << (lane_change ? "是" : "否") << std::endl;
    std::cout << "仿真时长： " << duration << " 秒" << std::endl;

    return 0;
}
eee_E2/config.ini
; 车辆仿真配置文件
[DriverAssist]
max_speed = 120.5      ; 最高巡航速度 (km/h)
lane_change_enabled = true ; 是否允许自动变道

[Simulation]
duration_s = 60        ; 仿真总时长 (秒)
eee_E2/CMakeLists.txt
cmake_minimum_required(VERSION 3.16)
project(eee_E2 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)

add_executable(eee_E2
    main.cpp
    external/inih/cpp/INIReader.cpp
    external/inih/ini.cpp
)
target_compile_definitions(eee_E2 PRIVATE
    CONFIG_FILE_PATH="${CMAKE_CURRENT_SOURCE_DIR}/config.ini")
