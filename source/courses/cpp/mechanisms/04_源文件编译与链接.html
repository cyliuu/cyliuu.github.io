// main.cpp 源程序
#include "math_utils.h"
#defineBASE_OFFSET 10
int main() {
int r = square(5) + BASE_OFFSET;
return r;
}
① 预处理 (-E)
main.cpp → main.i
② 编译 (-S)
main.i → main.s
③ 汇编 (-c)
main.s → main.o
④ 链接 (ld)
main.o → app.exe
// utils.h (接口声明 + 头文件卫哨)
#ifndef UTILS_H
#define UTILS_H
int multiply(int a, int b);
#endif
// main.cpp 调用 multiply(6, 7)
// utils.cpp 实现 multiply(int a, int b)
随堂交互检验 多文件编译时，若 main.cpp 包含了 utils.h 声明但构建命令漏编了 utils.cpp，会在哪个阶段报错？

预处理 (Preprocessing)

处理以 # 开头的指令：展开 #include 头文件、替换 #define 宏、剔除注释，生成纯 C++ 翻译单元 (.i)。

编译与汇编

编译器对语法和类型做严格检查并生成汇编代码 (.s)；汇编器将其翻译为含未决符号表的可重定位机器码 (.o/.obj)。

符号决议与重定位

链接器 (Linker) 将多个目标文件与库合并，把 main.o 中未决的 CALL ?multiply 填上 utils.o 中函数的真实地址。

Makefile 增量构建

通过比对目标文件 (.o) 与源文件 (.cpp/.h) 的最后修改时间戳，只重新编译改动过的编译单元，大幅缩短构建耗时。
