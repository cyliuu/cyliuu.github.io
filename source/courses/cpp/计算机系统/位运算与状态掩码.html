设置、清除、翻转状态位

固定八位无符号状态 · 教学协议
uint8_t mask = 1u << bit;
state |= mask;           // 设置
state &= ~mask;          // 清除，最终保留八位
state ^= mask;           // 翻转
bool on = (state & mask) != 0;
bit0 安全带、bit1 车门、bit2 发动机、bit3 雨刷；bit4～7 为保留位。这是本页自定义练习数据，不是示例 的报文定义。
