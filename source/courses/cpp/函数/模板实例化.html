推导 T 并比较两段距离

示例工程/main.cpp · 实际函数模板
template <typename T>
T find_closest(T dist1, T dist2) {
    return (dist1 < dist2) ? dist1 : dist2;
}
// 两个实参必须能推导出同一个 T，且 T 支持 < 比较。
源码注释说“支持 > 的类型”，但实际表达式使用 <；以代码为准。相等时三目运算选择第二个实参，数值结果仍相同。

判断题

直接调用 find_closest(50, 42.5f)，不显式指定 T，能否按本模板顺利推导？

int 输入限定为常见 32 位范围；float 数值使用浏览器 Math.fround 作 binary32 舍入示意。超出该模型范围的输入会被拒绝；C++ 的真实类型检查与代码生成仍由编译器完成。
